# 演讲稿

> 四个项目 · 约 25 分钟（含演示）
> 改稿日期：2026-10-09

---

## 开场

大家好。

今天讲四个项目。

先说清楚一件事：**这四个项目之间没关系**，各做各的，客户也不一样。

那为什么放一起讲？因为它们是从同一个想法里做出来的。

这个想法很简单：

**AI 现在很聪明了，但大部分人还是用不上。**

能生成一张图，能写一段话，看着挺厉害。但要真拿它干活、交货、赚钱，中间还差很远。

我们做的事，就是把这个"很远"补上。

下面一个一个说。

---

## 一、SoloSeed —— 帮一个人决定卖什么

先说第一个。

想问一下，在座有没有想自己做点生意、但一直没开始的？

*（停一下）*

没开始，通常不是不想，是不知道从哪下手。

卖什么？去哪找货？能不能赚钱？错了怎么办？

这几个问题答不上来，人就卡住了。卡三个月，热情就没了。

SoloSeed 就是解决这个的。

打开它，不是一个空白框让你自己填，是它已经把最近值得看的方向摆出来了——哪个品类在涨，哪个竞争没那么大。

你挑一个感兴趣的，然后跟它聊。

它给你推荐几个商品，帮你去 1688 找货源，把两三家工厂的价格、起订量、交期摆一起让你比，最后把成本一项一项摊开，算给你看能赚多少。售价还能拖着重算。

每一步你都能反悔。换商品、换工厂、改价格，都行。

它不替你做决定。

选完之后，它能帮你生成一个独立站，直接能访问的那种。顾客能看、能下单，你在后台能看到订单和利润。

**这个产品已经上线了。**

网址我放这儿，一会儿大家可以打开看：

**http://140.143.227.100:8000/**

我讲两个设计，做过生意的应该会有感觉。

**第一个，入库会查重。**

同一个商品你要是选进来两次，它会提醒你。要么合并，要么新增，要么换一个。因为库里要是堆了一堆重复的，后面建站、看板全乱。

**第二个，商品和站点是分开的。**

说白了就是：一个商品的成本、供应商、起订量，这是它自己的事，改一次全都跟着变。

但它在这个店里卖多少钱、叫什么名字、排第几，这是这个店的事。

分开有什么好处？同一个品，你可以在三个店卖三个价格，成本只用改一遍。

**试错便宜了，人就敢试了。**

最后说一句。

我们在页面上写了一句话，说利润测算只是辅助判断，**不保证你能赚到钱**。

有人建议我删掉，说不好看。

我没删。

因为想做生意的人，最不需要的就是再被人骗一次。

## 二、内容工厂 —— 帮做短剧的人把剧本做成片

第二个，做短剧、漫剧的会更关心。

现在想做这行的人很多，但做一集太慢，而且不稳。

- 人设不稳，上一集和这一集不像一个人
- 一个镜头废了，整集跟着重做
- 素材东一个西一个，找不回来
- 钱花出去了，不知道花在哪

我们做这个项目的时候，做了个挺笨的选择。

**我们没有先做"一键生成"的按钮。**

我们先去看别人是怎么做的。

两套课程，一集一集看完，**67 集，10 个多小时**。每一集拆开，画面截下来核对，方法记下来，失败的地方也记下来。

最后整理出一条 **8 个阶段的流程**，每个阶段要交什么、什么算通过，都写清楚。

还有一张表：**什么镜头该用什么方法生成**。简单动作用首帧，要指定终点的用首尾帧，多人对话用参考图，手机屏幕上的字别靠生成、后期自己合成。

这些比工具值钱。工具谁都能接模型，这些是我们花时间一点点看出来的。

然后才是产品。我们做了几件事。

**第一，把"人"和"图"分开管。**

"主角"是个概念。"主角第三版的定妆图"是一个文件。混在一起，做第二集就会挑错人。分开就好。

**第二，默认批量做。** 一次配好，成批出，你再挑。

**第三，给老板留了位置。** 谁花了多少钱、谁能用哪些功能、内容是不是审核过才发出去。

**第四，也是我想特别说的一条。**

我们给每个 AI 能力设了道门：**没有真实验证过的，就不开。**

宁可先关着。

我知道这话今天听着有点怪，大家都在说自己支持多少模型。但您可能遇到过——某个软件说有某个功能，您一用，发现不是那么回事。

我们不想做那种软件。

说实话，**这个项目我们还没做完**。

流程、界面、方法、模板都有了。成片的稳定性还在验。

我不想站这儿说"全跑通了"，因为不是真的。

做片子的朋友跟我说过一句话：**做片子骗不了人，片子一放出来，谁行谁不行一眼就看出来。**

所以这个项目，我宁愿让片子说话。

*（如果有成片，这里放。放完别说话，停两秒。）*

## 三、口播 Agent —— 帮说话的人剪片

第三个，给对着镜头说话的人。

做知识分享的、讲课的、带货的，都有个共同的日常：

**录一个小时，剪三个小时。**

剪的过程是这样：戴耳机从头听，听到"嗯""这个这个""我重新说一下"，停，切掉，接着听。听到停顿太长，停，切掉，接着听。

十分钟的内容，来回听三四遍。

在座有做内容的应该笑了，因为一点不夸张。

我们做的，就是把这段里最没技术含量的部分去掉。

停顿、等待、静音，我们叫**气口**。系统自己找出来，自己收紧。

给了三个档，因为内容不一样：

- 短视频要快要紧，选 **紧凑**
- 课程访谈要留呼吸感，选 **自然**

点一下就行。

口误、重复、口头禅，系统也听得出来，**标在时间轴上**。

注意，是标出来，不是替你剪掉。**你确认了它才动。**

这一点我们挺坚持的。**AI 负责提议，人负责拍板。** 剪片子最后的手感是创作者的。

还有个活也挺耗人——**做花字**。

一句话配一个动态标题，一条视频七八个，挑特效、排文字、对时长，一条条来。

我们内置了 **18 个现成的特效**，系统根据内容自动挑、自动改文案。你要做的是改一改，不是从零做。

最后说个我觉得最重要的。

**这些活儿，全在你自己电脑上做完。素材不出本机。**

问一句：**有没有那种内容，还没发布，你不敢传到云上的？**

客户的、内部的、还没到发布日期的。

这种内容，很多云工具是做不了的。不是技术上做不了，是**你不敢**。

所以我们选了难的那条路：识别、剪辑、渲染、导出全在本机。软件装上插上就用，素材从头到尾没动地方。

还有个细节，做渠道的会在意：**一张卡管一台机器**，谁用、用多久清清楚楚。而且不绑我们的账号，你可以用自己的 key，账自己算。

## 四、切片 —— 帮直播团队把内容切出来

第四个，做直播切片的。

一个直播间，播了四个小时。

四个小时里真正精彩的，可能就二十分钟，还散落在不同地方。

**问题是谁来找这二十分钟？**

现在是人在找。一个人或者几个人坐着看回放，倍速，来回拖。

这是最贵的成本，因为**没法规模化**。产量想翻倍，人就得翻倍。

我们做的，就是把这四个小时变成一条流水线。

主播什么时候开播，不用你盯，它盯着。开播自动录，结束自动收。录完自动转文字，转完自动把值得剪的地方找出来，找完自动做一版草稿。

**你把窗口关了去干别的，它还在跑。**

我们给自己定了个目标，叫"**首稿时间**"——从精彩的最后一段录完，到你能看到第一版草稿，希望控制在**十分钟**以内。

十分钟不算快。但重点不是十分钟，是**它变成了一个能说的数**。

以前老板问什么时候能出片，答案是"快了"。现在能说"十分钟"。

这两句话的差别，就是一个作坊和一个生意的差别。

再讲一个技术上的选择，我觉得挺关键。

很多同类工具用的是**录屏**——把浏览器窗口打开，录下来。

我们不是。我们录的是**直播源本身**。

差别是：

| | 录屏 | 我们 |
| --- | --- | --- |
| 要一直开着浏览器吗 | 要 | 不用 |
| 会录进鼠标、弹窗、通知吗 | 会 | 不会 |
| 电脑卡不卡 | 卡 | 不转码，占用低 |
| 画质 | 压过一遍 | 原始画质 |
| 会录进弹幕、礼物动画吗 | 会 | 不会 |

最后一条我想单独说：**不录弹幕，不录礼物动画，不录网页界面。**

因为我们做的是切片，不是翻录别人的页面。

还有一条底线得说清楚。

这行有灰色地带。有人会跟你说：验证码可以绕、Cookie 可以导、多弄几个代理、付费房间也有办法进。

**这些我们不做。**

不是做不到，是不做。

理由很实在：我们的客户是要长期做生意的。靠绕风控活下来的工具，用得越久风险越大。今天省的事，明天可能要账号来还。

所以我们的边界很清楚：**只看公开页面，只处理你有权处理的内容。**

这不是我们的上限，是我们的选择。

## 说几句实话

四个项目讲完了。

再说一遍，它们没什么关系。一个帮人决定卖什么，一个帮人把剧本做成片，一个帮人剪口播，一个帮人切直播。客户不同，做法也不同。

但我们在每件事上都做了同一个选择：**选了慢的那条。**

- 做商机的时候，明明可以把利润数字写得更好看，我们加了免责声明
- 做内容工厂的时候，明明可以先喊"一键成片"，我们先去看完了 67 集课程
- 做口播的时候，明明可以让素材传上来省事，我们做成了本机处理
- 做切片的时候，明明有"效率更高"的路子，我们把边界写死了

单看每一件都不划算。

合起来是我们唯一拿得出手的东西：

**我们说的话，你可以去验。**

想找的是能一起做事的人。

- 你手上有客户、有渠道，知道谁需要这些，我们可以一起做

价格和条件今天不讲。一次演讲也建立不了信任。

我能做的是把东西摆你面前：**能打开的打开看，能跑的现场跑。你自己判断。**

最后一句。

这四个项目，都还没到该有的样子。内容工厂还在验，客户端发行还在收尾，还有一个刚上线，用户还很少。

要是你想看一个已经功成名就的项目，那今天要失望了。

但我能保证一件事：

**我没跟你讲一句不实的话。讲了的都能查，没讲的你问我也告诉你。**

谢谢。

## 不能说 / 要这么说

| 不能说 | 要这么说 |
| --- | --- |
| 切片"十分钟出片" | "**目标**是十分钟以内" |
| 内容工厂"已经跑通" | "流程和方法都在，成片稳定性**还在验**" |
| "支持 XX 模型"（没验过） | 不说支持，或说"还在验收" |
| 切片的识别准确率 | **别提任何数字**（缺真实样本） |

| "百分百准" | "能自动给建议，不保证一条不漏" |
| 任何收益、爆款、转化承诺 | 一律不承诺 |
