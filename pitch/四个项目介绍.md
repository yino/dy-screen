## 我们做什么

我们做 AI 落地。

手上四个项目，**互相独立**。客户不一样，做法不一样，也不共用一套东西。

它们的共同点只有一个：

**把 AI 从"能演示"，变成"能用、能交货"。**

AI 现在很聪明，能生成图，能写文字，看着挺厉害。但真要拿它干活、赚钱，中间还差很远。

差的不是算力，不是模型，也不是钱。差的是一堆没人愿意花时间去做的事：流程、检查、返工、验收、边界、责任。

我们做的就是这些。

| 项目 | 一句话 |
| --- | --- |
| **SoloSeed** | 帮一个人决定卖什么，并把店开起来 |
| **内容工厂** | 帮做短剧的把剧本做成片 |
| **口播 Agent** | 帮对着镜头说话的人剪片 |
| **切片** | 帮直播团队把内容切出来 |

下面一个一个讲。

## 一、SoloSeed —— 帮一个人开始做生意

### 解决什么问题

想自己做生意、但一直没开始的人，卡在哪儿？

不是不想，是不知道从哪下手。

卖什么？去哪找货？能不能赚钱？错了怎么办？

这几个问题答不上来，人就卡住了。卡三个月，热情就没了。

### 怎么做

**打开不是一个空白框。** 它已经把最近值得看的方向摆出来了——哪个品类在涨，哪个竞争没那么大。

你挑一个感兴趣的，然后跟它聊：

1. 它推荐几个商品
2. 帮你去 1688 找货源
3. 把两三家工厂的价格、起订量、交期摆一起让你比
4. 把成本一项一项摊开，算给你看能赚多少，售价还能拖着重算

**每一步你都能反悔。** 换商品、换工厂、改价格都行。

它不替你做决定。

选完之后，能帮你生成一个独立站，直接能访问。顾客能看、能下单，你在后台能看到订单和利润。

### 两个设计，值得单独说

**一、入库会查重**

同一个商品选进来两次，它会提醒你：合并、新增，还是换一个。

因为库里要是堆了一堆重复的，后面建站、看板全乱。

**二、商品和站点是分开的**

一个商品自己的事：成本、供应商、起订量。改一次，全都跟着变。

一个商品在这个店里的事：卖多少钱、叫什么名字、排第几。各店可以不一样。

分开的好处很实在——**同一个品，你可以在三个店卖三个价格，成本只用改一遍。**

试错便宜了，人就敢试了。

### 一个取舍

我们在页面上写了一句话：利润测算只是辅助判断，**不保证能赚到钱**。

有人建议删掉，说不好看。

没删。

因为想做生意的人，最不需要的就是再被人骗一次。

### 现在的状态

**已经上线。** 可以直接打开看：

**http://140.143.227.100:8000/**

### 边界

- 现在不做在线支付，"确认下单"生成订单，收款走线下或另接
- 后台管理页没有登录鉴权，适合内网和演示，**上公网前要加访问控制**
- 目前跑在一台服务器上，适合中小流量
- 自动生成外部网站、图片搜同款属于可选功能，默认关闭

## 二、内容工厂 —— 帮做短剧的把剧本做成片

### 解决什么问题

现在想做短剧、漫剧的人很多，但做一集太慢，而且不稳。

- 人设不稳，上一集和这一集不像一个人
- 一个镜头废了，整集跟着重做
- 素材东一个西一个，找不回来
- 钱花出去了，不知道花在哪

### 我们做这个项目时，先做了件笨事

我们**没有先做"一键生成"的按钮**。

我们先去看别人是怎么做的。

两套课程，一集一集看完，**67 集，10 个多小时**。每一集拆开，画面截下来核对，方法记下来，失败的地方也记下来。

整理出来的东西：

- 一条 **8 个阶段的制作流程**，每个阶段要交什么、什么算通过，都写清楚
- 一张表：**什么镜头该用什么方法生成**
  - 简单动作用首帧
  - 要指定终点的用首尾帧
  - 多人对话用参考图
  - 手机屏幕上的字别靠生成，后期自己合成
- 一套可以直接拿来填的**记录表**

这些比工具值钱。工具谁都能接模型，这些是我们花时间一点点看出来的。

### 产品上做了四件事

**一、把"人"和"图"分开管**

"主角"是个概念。"主角第三版的定妆图"是一个文件。

混在一起，做第二集就会挑错人。分开就好。

**二、默认批量做**

一次配好，成批出，你再挑。

**三、给老板留了位置**

谁花了多少钱、谁能用哪些功能、内容是不是审核过才发出去。

**四、给每个 AI 能力设了道门**

**没有真实验证过的，就不开。** 宁可先关着。

这话听起来有点怪，大家都在说自己支持多少模型。但您可能遇到过——某个软件说有某个功能，您一用，发现不是那么回事。

我们不想做那种软件。

### 现在的状态

**这个项目还没做完。**

流程、界面、方法、模板都有了。**成片的稳定性还在验。**

我们不想说"已经全跑通了"，因为不是真的。

做片子的朋友说过一句话：做片子骗不了人，片子一放出来，谁行谁不行一眼就看出来。

所以这个项目，我们更愿意让片子说话。

### 边界

- 尚未通过内部发布门槛
- 没有拿到真实调用证据的模型，**我们不宣称支持**
- 有一个上游服务商已停止服务，对应能力明确延期

## 三、口播 Agent —— 帮说话的人剪片

### 解决什么问题

做知识分享的、讲课的、带货的，都有个共同的日常：

**录一个小时，剪三个小时。**

剪的过程是这样：戴耳机从头听，听到"嗯""这个这个""我重新说一下"，停，切掉，接着听。听到停顿太长，停，切掉，接着听。

十分钟的内容，来回听三四遍。

### 怎么做

**一、自动剪气口**

停顿、等待、静音，我们叫"气口"。系统自己找出来，自己收紧。

给了三个档，因为内容不一样：

| 档位 | 适合 |
| --- | --- |
| 紧凑 | 短视频，节奏快 |
| 均衡 | 通用 |
| 自然（默认） | 课程、访谈、长讲解，保留呼吸感 |

点一下就行。

**二、自动剪卡壳**

口误、重复、口头禅，系统听得出来，**标在时间轴上**。

注意：是标出来，不是替你剪掉。**你确认了它才动。**

这一点我们挺坚持的——**AI 负责提议，人负责拍板。** 剪片子最后的手感是创作者的。

**三、18 个现成的花字特效**

一句话配一个动态标题，一条视频七八个，挑特效、排文字、对时长，一条条来——这活最耗人。

系统会根据内容自动挑特效、自动改文案。你要做的是改一改，不是从零做。

**四、字幕、封面、包装、背景音乐**

一条龙，模板化，风格统一。

**五、也是最关键的一条：全在你自己电脑上做完**

**素材不出本机。**

问一句：**有没有那种内容，还没发布，你不敢传到云上的？**

客户的、内部的、还没到发布日期的。

这种内容，很多云工具做不了。不是技术上做不了，是**你不敢**。

所以我们选了难的那条路：识别、剪辑、渲染、导出全在本机。软件装上插上就用，素材从头到尾没动地方。

**六、授权清楚**

一张卡管一台机器，谁用、用多久清清楚楚。

而且不绑我们的账号，你可以用自己的 key，账自己算。

### 现在的状态

功能齐全。**Windows 安装包和真机验证还在收尾**，完成前不承诺可交付。

### 边界

- 口误和气口识别**能自动给建议，但不保证一条不漏、一条不错**，还要用真实样本再验一遍
- 字幕样式当前是固定的，不支持改字体、颜色、位置

## 四、切片 —— 帮直播团队把内容切出来

### 解决什么问题

一个直播间，播了四个小时。

四个小时里真正精彩的，可能就二十分钟，还散落在不同地方。

**问题是谁来找这二十分钟？**

现在是人在找。一个人或者几个人坐着看回放，倍速，来回拖。

这是最贵的成本，因为**没法规模化**。产量想翻倍，人就得翻倍。

### 怎么做

主播什么时候开播，不用你盯，它盯着。开播自动录，结束自动收。录完自动转文字，转完自动把值得剪的地方找出来，找完自动做一版草稿。

**你把窗口关了去干别的，它还在跑。**

**首稿时间**：我们定的目标是——从精彩的最后一段录完，到你能看到第一版草稿，控制在**十分钟**以内。

十分钟不算快。但重点不是十分钟，是**它变成了一个能说的数**。

以前老板问什么时候能出片，答案是"快了"。现在能说"十分钟"。

这两句话的差别，就是一个作坊和一个生意的差别。

### 一个技术上的选择

很多同类工具用的是**录屏**——把浏览器窗口打开，录下来。

我们不是。我们录的是**直播源本身**。

| | 录屏 | 我们 |
| --- | --- | --- |
| 要一直开着浏览器吗 | 要 | 不用 |
| 会录进鼠标、弹窗、通知吗 | 会 | 不会 |
| 电脑卡不卡 | 卡 | 不转码，占用低 |
| 画质 | 压过一遍 | 原始画质 |
| 会录进弹幕、礼物动画吗 | 会 | 不会 |

最后一条单独说：**不录弹幕，不录礼物动画，不录网页界面。**

因为我们做的是切片，不是翻录别人的页面。

### 一条底线

这行有灰色地带。有人会跟你说：验证码可以绕、Cookie 可以导、多弄几个代理、付费房间也有办法进。

**这些我们不做。**

不是做不到，是不做。

理由很实在：我们的客户是要长期做生意的。靠绕风控活下来的工具，用得越久风险越大。今天省的事，明天可能要账号来还。

所以边界很清楚：**只看公开页面，只处理你有权处理的内容。**

这不是我们的上限，是我们的选择。

### 现在的状态

桌面客户端 **v0.3.0 已交付**。

支持 macOS（Apple 芯片和 Intel）和 Windows 64 位，三个平台同等对待。

**还在收尾的**：正式签名与公证、干净电脑离线安装验证、至少 10 场真实直播的识别质量测试。

### 边界

- 不能改原始文字记录，不能导出标准字幕文件（SRT/ASS）
- 不做说话人区分，不做字级时间戳
- 不能剪原始录像，**原片永远只读**
- 播放器一次只能看一段，不能把一整场拼起来连播
- 字幕样式固定，不支持改字体颜色位置

## 我们不做的事

这一节写在前面，因为合作之前说清楚，比合作之后扯皮好。

| 不做 | 原因 |
| --- | --- |
| 不承诺"全自动、不用人管" | 成片和生意决策还是要人做最后判断 |
| 不承诺爆款率、转化率、收益 | 内容有运气成分 |
| 不碰绕过平台风控的事 | 不绕验证码、不导 Cookie、不用代理池——会让客户的账号有风险 |
| 不承诺支持所有平台 | 切片目前只面向抖音公开页面 |
| 不把目标值说成实测值 | 十成首稿、提效比例这些都是目标，实测数据我们会另给 |
| 不宣称没验收过的能力 | 没有真实调用证据，就不说"已支持" |

## 常见问题

**这四个项目是什么关系？**

没有关系。四个独立项目，客户不同、做法不同。共同点只有一个判断：AI 要真能用起来，得有人把流程、检查、验收这些事做掉。

**和剪映、和别的 AI 工具有什么区别？**

剪映是给人省力的工具。我们做的是产能和验收标准——多久出、几个人、质量怎么对账。

**AI 做的东西能看吗？**

直接看片子。我们不辩解。

**会不会被封号？**

不绕验证码、不导 Cookie、不用代理池、不碰付费和私密直播间。只处理公开页面。这些我们比客户更怕，所以一开始就没做这些功能。

**我的内容会不会被上传？**

口播 Agent 和切片都是本机处理。切片的内容出网只有两条路，而且都要用户当场授权。

**SoloSeed 页面上的数字是真的吗？**

落地页上写明了"数字为示意"，那是展示用的。**产品里面的**机会数据才是真实统计。

**你们现在有多少用户？**

如实回答。数字不好看就说不好看。
