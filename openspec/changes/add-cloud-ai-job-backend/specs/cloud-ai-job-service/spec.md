> 状态：**已搁置（本轮不实施）**。当前口径下客户端持 `ai/llm-ak` 短期 token 直连百炼完成 ASR、LLM、图片与视频生成，admin-service 本轮不新增任何接口。本 delta 仅作为历史设计保留，不参与本轮验收。

## Purpose

为桌面客户端提供可记账、可幂等、可对账的云端 AI 任务服务，使服务端持有上游 Provider 长期凭据并管理付费调用、异步任务与分项额度，客户端只持有短期任务令牌。

## ADDED Requirements

### Requirement: 创建 AI 任务并冻结策略与预算
系统 SHALL 提供 `POST /api/client/ai/runs` 创建 AI 任务，并 SHALL 在响应中返回绑定用户、设备、任务、模型、有效期与预算的短期模型网关令牌。系统 MUST 在创建时冻结任务策略与预算，并 MUST NOT 在设备鉴权无效时创建任务。

#### Scenario: 创建任务成功
- **WHEN** 客户端以有效设备鉴权提交任务类型、输入指纹与请求 ID
- **THEN** 系统返回业务任务 ID、冻结后的策略与预算摘要，以及只对该任务有效的短期网关令牌

#### Scenario: 设备鉴权无效
- **WHEN** 请求缺少权威 `device_id` 或 `activate_code`，或授权已失效
- **THEN** 系统拒绝创建任务、不预留任何额度，也不签发网关令牌

#### Scenario: 同键不同输入
- **WHEN** 相同 `(账号, 任务类型, requestId)` 已存在但本次输入指纹不同
- **THEN** 系统拒绝该请求并返回冲突错误，不复用也不覆盖原任务

### Requirement: 签发临时音频受限直传凭证
系统 SHALL 提供 `POST /api/client/ai/uploads` 签发仅限单个对象键、声明大小上限与有效期的上传凭证。凭证 MUST 只允许写入该对象键、MUST NOT 包含上游长期密钥，且签发的对象 MUST NOT 永久公开。

#### Scenario: 签发凭证
- **WHEN** 客户端以有效设备鉴权申请临时音频上传凭证并声明大小与用途
- **THEN** 系统返回限定对象键、大小上限、有效期与不含长期凭据的直传信息

#### Scenario: 超出声明大小
- **WHEN** 客户端上传的实际字节数超过声明上限
- **THEN** 系统拒绝该资产，且该资产不得用于创建 ASR 任务

#### Scenario: 凭证过期后继续使用
- **WHEN** 客户端在凭证有效期外尝试写入
- **THEN** 对象存储拒绝写入，系统不因过期凭证产生任何付费调用

### Requirement: 创建或复用阿里云 ASR 任务
系统 SHALL 提供 `POST /api/client/ai/asr-jobs`，在验证资产归属与额度后提交阿里云异步文件转写，并 SHALL 保存上游任务 ID 与业务任务 ID 的对应关系。系统 MUST NOT 接受客户端提交的本地路径、`file://` URI 或任意远程地址。

#### Scenario: 创建 ASR 任务
- **WHEN** 客户端提交不含本地路径的 `audioAssetId`、分块序号与源音频偏移
- **THEN** 系统校验资产归属与额度，提交上游异步转写并返回业务任务 ID 与初始状态

#### Scenario: 资产不属于当前账号
- **WHEN** 提交的 `audioAssetId` 不属于当前账号或已过保留期
- **THEN** 系统拒绝创建任务、不产生上游付费调用，并返回脱敏错误

#### Scenario: 额度不足
- **WHEN** 该账号剩余的 ASR 时长额度不足以覆盖声明的音频时长
- **THEN** 系统拒绝创建任务、不提交上游请求，并返回可区分的额度错误码

#### Scenario: 按分块组织子任务
- **WHEN** 同一来源输入 ID 以多个分块序号与源音频偏移提交
- **THEN** 系统以同一来源输入 ID 组织多个 ASR 子任务，并保持每块的偏移可还原到源视频时间

### Requirement: 为 Harness 提供兼容且支持流式的模型网关
系统 SHALL 提供 `POST /api/client/ai/llm/v1/chat/completions`，使用服务端长期密钥调用上游模型，并 SHALL 透传调用方实际使用的消息、工具调用、流式响应与结束原因。系统 MUST 在服务端记录真实 token 用量，MUST NOT 向客户端下发上游长期密钥，也 MUST NOT 接受客户端自行报告的价格或剩余额度。

#### Scenario: 流式调用
- **WHEN** 客户端以任务网关令牌发起流式对话请求
- **THEN** 系统边转发上游增量边保持响应顺序与结束原因，并在完成时结算真实 token 用量

#### Scenario: 网关令牌过期或超出预算
- **WHEN** 令牌已过期、不属于该任务或该任务预算已耗尽
- **THEN** 系统拒绝请求、不再调用上游，并返回可区分的鉴权或预算错误

#### Scenario: 上游流式中断
- **WHEN** 上游在流式响应中途断开或返回错误
- **THEN** 系统按已实际产生的用量结算并返回脱敏错误，不把中断伪装为正常结束

### Requirement: 创建或复用参考图与图生视频任务
系统 SHALL 提供 `POST /api/client/ai/image-jobs` 与 `POST /api/client/ai/video-jobs` 创建或复用媒体生成任务，并 SHALL 对参考图与视频分别执行独立的提交次数上限与任务级门禁。系统 MUST NOT 向客户端下发上游 Provider 凭据或任意下载地址。

#### Scenario: 创建参考图任务
- **WHEN** 客户端提交结构化分镜与参考图提示词，且该任务仍有剩余图片次数
- **THEN** 系统预留额度并提交上游图片生成，返回业务任务 ID

#### Scenario: 超出任务级动画门禁
- **WHEN** 提交的视频生成请求超出该任务允许的动画数量、累计秒数或金额上限
- **THEN** 系统拒绝提交、不产生上游费用，并返回可区分的门禁错误码

#### Scenario: 复用已成功的生成结果
- **WHEN** 以相同输入指纹重复提交同一媒体生成请求
- **THEN** 系统返回已有的业务任务 ID 与资产引用，不向上游重复付费

### Requirement: 查询云端任务终态、用量与资产
系统 SHALL 提供 `GET /api/client/ai/jobs/{jobId}` 返回任务终态、分项用量与已校验的资产信息。成功结果 SHALL 返回资产 ID、哈希、尺寸、帧率、实际时长与受控下载地址。

#### Scenario: 查询进行中的任务
- **WHEN** 客户端查询尚未到达终态的任务
- **THEN** 系统返回当前状态与已产生的用量，不返回未完成的资产引用

#### Scenario: 查询成功任务
- **WHEN** 任务已成功完成
- **THEN** 系统返回资产 ID、哈希、尺寸、帧率、实际时长与受控下载地址，并给出该任务的结算用量

#### Scenario: 查询失败或取消任务
- **WHEN** 任务已失败或被取消
- **THEN** 系统返回终止原因分类、是否仍会产生上游费用，以及已实际结算的用量

### Requirement: 按幂等请求 ID 找回已有任务
系统 SHALL 提供 `GET /api/client/ai/jobs/by-request/{requestId}`，使客户端在未收到任务 ID 时按键找回原任务。`(账号, 任务类型, requestId)` MUST 在服务端唯一；同键同输入 SHALL 返回原任务，同键不同输入 MUST 被拒绝。

#### Scenario: 客户端未收到任务 ID
- **WHEN** 客户端因超时或崩溃未取得业务任务 ID，并以原请求 ID 查询
- **THEN** 系统返回原任务的业务任务 ID 与当前状态，不创建新任务

#### Scenario: 同键同输入重复提交
- **WHEN** 客户端以相同请求 ID 和相同输入重复提交
- **THEN** 系统返回原任务，且不产生第二次上游付费调用

### Requirement: 请求取消并区分上游费用
系统 SHALL 提供 `POST /api/client/ai/jobs/{jobId}/cancel` 请求取消任务，并 SHALL 在响应中说明是否仍会产生上游费用。上游不支持取消时，系统 SHALL 停止后续步骤与结果应用，但 MUST 按实际用量结算已提交的请求。

#### Scenario: 上游支持取消
- **WHEN** 客户端取消一个上游仍可取消的任务
- **THEN** 系统停止该任务并返回取消成功与不再产生上游费用的结论

#### Scenario: 上游不支持取消
- **WHEN** 客户端取消一个上游已提交且不可取消的任务
- **THEN** 系统停止后续步骤与结果应用，返回仍会按实际用量结算的结论，并在上游完成后按真实用量结算

#### Scenario: 取消后不产生重复付费
- **WHEN** 客户端取消后再次以同一请求 ID 提交
- **THEN** 系统返回已取消的原任务，MUST NOT 自动重新提交付费请求

### Requirement: 按 Provider 调用分项记账
系统 SHALL 按 ASR 时长、模型 token、图片次数与规格、视频次数与秒数分别记录用量，并 SHALL 在付费提交前原子预留额度、取得上游结果后结算。系统 MUST 拒绝客户端自行报告的价格或剩余额度。

#### Scenario: 预留后失败
- **WHEN** 已预留额度的任务在取得上游结果前失败
- **THEN** 系统释放该次预留，并只对已实际产生的上游用量结算

#### Scenario: 结算成功调用
- **WHEN** 上游返回成功结果
- **THEN** 系统按真实用量结算并把差额返还到对应分项额度

#### Scenario: 客户端自报用量
- **WHEN** 客户端在请求中提交价格、单价或剩余额度
- **THEN** 系统不把这些字段作为结算依据，只使用服务端测量值或上游返回值

### Requirement: 保持待对账状态而不重复提交付费请求
系统 SHALL 在已向上游提交但无法确认是否创建成功时保持待对账状态，并 SHALL 通过查询上游或人工处理消解该状态。系统 MUST NOT 在待对账状态下自动再次提交同一付费请求。

#### Scenario: 上游提交结果不确定
- **WHEN** 上游请求超时或返回无法解析的响应，无法确认任务是否已创建
- **THEN** 系统把该任务标记为待对账、保留请求 ID 与输入指纹，并阻止自动重试付费提交

#### Scenario: 对账确认上游任务存在
- **WHEN** 后续查询上游确认该任务已创建
- **THEN** 系统绑定上游任务 ID、把任务转入正常状态并继续结算，不发生第二次付费提交

#### Scenario: 对账确认上游任务不存在
- **WHEN** 后续查询上游确认该任务从未创建
- **THEN** 系统释放预留额度并把任务标记为可安全重试，由客户端以同一请求 ID 决定是否重新提交

### Requirement: 受限资产保留与幂等清理
系统 SHALL 保证临时音频在上游读取与任务轮询期间可用，并 SHALL 在任务终止后按保留策略删除。清理 MUST 幂等；清理失败时系统 SHALL 保留成功结果并重试清理，MUST NOT 因清理失败重新发起付费转写。

#### Scenario: 任务正常终止
- **WHEN** 云端 ASR 任务到达成功、失败或取消终态
- **THEN** 系统按保留策略删除临时音频，并把清理结果记录为可查询状态

#### Scenario: 清理失败但结果已成功
- **WHEN** 转写已成功但对象清理失败
- **THEN** 系统保留成功结果、标记清理待重试，且不得重新提交转写

#### Scenario: 重复清理
- **WHEN** 同一资产的清理操作被重复执行
- **THEN** 系统返回幂等成功，不产生错误也不影响已发布的结果

### Requirement: 服务端日志与遥测脱敏
服务端 SHALL 只记录完成任务必需的资产引用、用量和脱敏错误。上游凭据、完整提示词、ASR 正文、本地路径与签名下载地址 MUST NOT 进入普通日志与遥测。

#### Scenario: 记录任务失败
- **WHEN** 任务因上游错误失败
- **THEN** 服务端记录错误分类、任务 ID、用量与资产引用，且日志中不含上游凭据、完整提示词、ASR 正文或签名下载地址

#### Scenario: 上报统计遥测
- **WHEN** 服务端产生面向统计的遥测事件
- **THEN** 事件只包含任务类型、状态、分项用量与耗时，不包含用户内容
