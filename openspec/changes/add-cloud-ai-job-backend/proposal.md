## Why

v2 要求客户端把临时音频上传、云端转写、模型调用、参考图与图生视频四类付费调用都交给服务端持有凭据并记账。当前服务端只在 `GET /api/client/ai/llm-ak` 签发短期令牌后即脱手，客户端直连上游 Provider，服务端无法确认付费调用是否真的发生、用量是多少，也无法在客户端超时、崩溃或断线时止损与对账。这四类能力全部依赖服务端成为可记账的代理，因此服务端接口必须先完成。

## What Changes

- 新增 9 个客户端 AI 接口，覆盖任务创建与预算冻结、临时音频受限直传凭证、ASR 任务、模型网关、参考图任务、图生视频任务、任务查询、按幂等请求 ID 找回任务和取消请求。
- 服务端角色从"签发即脱手"改为"代理并记账"：上游凭据只保存在服务端，客户端只持有绑定用户、设备、任务、模型、有效期和预算的短期令牌。
- 新增 `(账号, 任务类型, requestId)` 唯一约束：同键同输入返回原任务，同键不同输入拒绝。客户端未收到任务 ID 时可按键找回，不重复提交付费请求。
- 新增按 ASR 时长、LLM token、图片次数与规格、视频次数与秒数分别记账的预算账本，付费提交前原子预留、取得上游结果后结算，服务端拒绝客户端自报的价格与剩余额度。
- 新增待对账状态：服务端已向上游提交但无法确认是否创建成功时保持待对账，查询上游或人工处理，不自动再次提交付费请求。
- 新增临时音频与生成资产的保留期与清理状态，清理失败保留成功结果并重试清理。
- 扩展心跳下发的服务端权威信号，让客户端能显示 AI 各分项预算；客户端不得以本地设置替代服务端额度。
- 非目标：本次不实现客户端侧的上传器、Harness sidecar、代码渲染与动画合成；不改变激活、心跳、监听、录制和本地 ASR 的现有行为；不为桌面任务常驻服务端 Agent runner；不实现管理后台的账单与用量展示界面；不引入登录、验证码、DRM 或私有直播间访问控制的绕过。

## 搁置后仅保留的两项

本 change 整体搁置，只有两项语义被当前口径复用，作为实现输入：

1. `(账号, 任务类型, requestId)` 的幂等语义——在当前口径下实现为**客户端本地 SQLite** 落盘 `requestId` 与输入指纹：同键同输入返回原任务记录，同键不同输入拒绝；重试只做同键复用，不产生重复付费。分别落在 `wire-cloud-asr-upload-and-jobs` 与 `add-generative-video-animation`。
2. 客户端 `src-tauri/src/api.rs` 单一 API 客户端的契约对齐方式——业务模块不得绕过它直接发起请求。ASR 与生成链路改为直连百炼后，该约束仍适用于既有的 `activate`、`heartbeat` 与 `ai/llm-ak` 三个接口。

其余内容（9 个客户端 AI 接口、分项预算账本、原子预留与结算、待对账状态、资产保留与清理、心跳分项预算信号）**本轮不实施**，仅作为历史设计保留。

## Capabilities

### New Capabilities

- `cloud-ai-job-service`: 服务端 AI 上传凭证、ASR/图片/视频任务、模型网关、幂等请求、预算账本、上游对账与资产保留清理。

### Modified Capabilities

- `client-activation-service`: 心跳新增 AI 分项预算信号；9 个 AI 接口复用现有设备鉴权与单一 Rust API 客户端，并要求服务端额度对客户端权威。

## Impact

- 后端仓库：实现在独立的 `admin-service`（Next.js 14 App Router + Prisma + PostgreSQL + Redis + 网宿 EdgeRay 对象存储），不在本仓库。本仓库只产出接口契约、客户端消费约定与验收口径。
- 数据模型：需要任务的付费记录表、`(账号, 任务类型, requestId)` 唯一索引、预算预留与结算字段、上游任务 ID 与待对账状态、资产保留期与清理状态；现有 `ai_quotas`、`ai_usage_logs`、`llm_duration_usage_logs` 的计数语义需要与新的分项账本对齐。
- 对象存储：现有 `S3ObjectStorage` 只有服务端上传且使用 `public-read` 与永久公开地址，需要新增受限直传凭证、有效期与删除能力；临时音频不得永久公开。
- 客户端：`src-tauri/src/api.rs` 的单一 API 客户端需要承载 9 个新接口；`src-tauri/src/ai/repository.rs` 需要为付费提交前持久化稳定 `requestId` 提供本地事务支持（具体客户端行为在后续 change 交付）。
- 隐私与合规：提示词与 ASR 正文将经由服务端，需要落地脱敏日志、保留期清理和"不写入普通日志与遥测"的验收证据；上游凭据、完整提示词、ASR 正文、本地路径与签名下载地址不得进入普通日志。
- 上游依赖：阿里云百炼文件转写、DeepSeek 兼容网关、图片生成与图生视频 Provider；图片与视频 Provider 的选型与配额上限需要在实现前确认并纳入服务端版本化配置。
