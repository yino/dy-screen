## MODIFIED Requirements

### Requirement: 保持数据本地和输出脱敏
系统 MUST NOT 上传主播、视频、AI 项目、设置、页面诊断或使用数据。系统 SHALL 存在两个且仅两个用户内容例外：经用户显式授权后把标准临时音频直传阿里云百炼用于云端转写，以及经用户显式授权后把最小文本直连百炼发送给模型。除这两个例外，系统 MUST NOT 上传转写或使用数据。系统 MUST NOT 在日志、事件、界面错误或 CLI 诊断中暴露签名 URL 查询字符串、Cookie、页面正文、React Flight 原始载荷、短期 token 或未经脱敏的本地媒体路径。

#### Scenario: backend 返回直播流错误
- **WHEN** 错误与签名 CDN 地址有关
- **THEN** 前端只接收脱敏后的中文错误

#### Scenario: 本地 ASR 运行
- **WHEN** 用户启动 AI 分析项目且本次执行本地识别路径
- **THEN** 后端只访问经过验证的本地媒体和随包模型，不发起网络请求或媒体、转写上传

#### Scenario: 用户运行直播间诊断
- **WHEN** CLI 完成公开直播间诊断
- **THEN** 输出仅包含允许的 HTTP 元信息、安全 marker、分类和脱敏错误

#### Scenario: 上传临时音频用于云端转写
- **WHEN** 用户已授权云端转写且本次走云端识别路径
- **THEN** 系统只上传任务生命周期内生成的标准音频到百炼，并在任务结束、失败或取消后清理本地临时音频，不上传原始视频或录像

#### Scenario: 经授权发送最小文本
- **WHEN** 用户显式确认精彩分析、转场匹配或文本纠错的发送范围
- **THEN** 系统只直连百炼发送该范围允许的最小文本字段，不发送视频、音频、本地路径、签名流地址或数据库其他内容

### Requirement: 在设置页管理 DeepSeek
系统 SHALL 在设置页展示当前生效模型、解析来源、下次解析时间、短期 token 可用状态，以及 heartbeat 判定的账号开通与额度状态，并 SHALL 提供受控的连接诊断入口。系统 MUST NOT 提供上游 API Key 的输入、保存、替换或清除入口，也 MUST NOT 在读取设置或重新打开页面时回填任何凭据内容或短期 token。

#### Scenario: 保存并重新打开设置
- **WHEN** 用户保存阈值后再次打开设置页
- **THEN** 界面显示阈值、当前模型、解析来源与可用状态，且 DOM、浏览器演示数据和日志均不包含任何凭据内容或短期 token

#### Scenario: 测试连接
- **WHEN** 用户点击测试连接
- **THEN** 界面展示加载状态及后端返回的成功或脱敏错误，并防止重复提交

#### Scenario: 账号未开通或额度耗尽
- **WHEN** 心跳或诊断表明账号未开通 AI 服务或某一额度已耗尽
- **THEN** 设置页与相关入口显示可区分的中文原因，并在额度耗尽时阻止发起新的付费调用
