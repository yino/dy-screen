## MODIFIED Requirements

### Requirement: 维护受信运行资源清单
系统 SHALL 使用版本化 manifest 描述当前平台所需的 FFmpeg、FFprobe、Whisper、VAD、模型、规范化字典、渲染运行时、固定版本渲染浏览器、渲染器引擎脚本、Harness 运行时、锁定字体、许可证和平台运行时，并 SHALL 为每个组件保存版本、相对路径、大小、SHA-256、最低应用版本和许可证引用。渲染器引擎脚本 SHALL 以可独立校验的条目声明版本与哈希，MUST NOT 允许运行期加载 manifest 之外的脚本。

#### Scenario: 读取有效资源清单
- **WHEN** 应用读取内嵌或已安装的 manifest
- **THEN** 后端校验 schema、应用版本、操作系统、架构和必需组件集合，并返回脱敏的资源诊断状态

#### Scenario: 清单缺少平台组件
- **WHEN** manifest 没有当前平台的必需组件或声明了不支持的架构
- **THEN** 系统将资源状态标记为不可用，不解析任何未声明的可执行文件

#### Scenario: 渲染运行时与渲染浏览器组件
- **WHEN** manifest 声明渲染运行时、固定版本渲染浏览器、渲染器引擎脚本与锁定字体组件
- **THEN** 后端按其声明的版本、相对路径、大小和 SHA-256 完成校验后才允许启动渲染，并把渲染运行时、渲染浏览器、引擎脚本与 Harness 运行时作为可独立诊断的组件分别报告状态

#### Scenario: 引擎脚本条目缺失或校验失败
- **WHEN** manifest 未声明引擎脚本条目，或其版本、哈希与随包内容不一致
- **THEN** 系统把渲染能力标记为不可用并拒绝渲染，不解析或执行任何未声明的脚本

#### Scenario: 基础能力不依赖增强组件
- **WHEN** 渲染运行时、渲染浏览器或 Harness 运行时组件缺失、损坏或版本不符
- **THEN** 系统只把增强相关能力标记为不可用，保持录制、视频库浏览、预览、封面与本地 ASR 可用
