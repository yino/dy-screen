## MODIFIED Requirements

### Requirement: 按授权优先使用阿里云 ASR
系统 SHALL 在开始一次 ASR 输入处理前，通过已鉴权的 `GET /api/client/ai/llm-ak` 获取临时 AI 密钥；仅当响应成功、`provider` 为 `ALI`、密钥非空且 `expireAt` 未过期时，才允许从客户端直连提交阿里云百炼 ASR。授权与额度问题 MUST 显式报告，MUST NOT 被描述为云端故障，也 MUST NOT 触发自动本地回退。

#### Scenario: 临时密钥有效
- **WHEN** 服务端返回有效临时密钥且 provider 为 `ALI`
- **THEN** 系统使用该密钥以 Bearer 方式从客户端直连提交百炼文件转写任务，并不启动本地识别作为首选路径

#### Scenario: 未授权或额度耗尽
- **WHEN** `/api/client/ai/llm-ak` 返回 `3001`、`3003` 或 `3004`，或 heartbeat 响应表明账号未开通、额度已耗尽
- **THEN** 系统显示对应的中文授权/次数/时长提示并明确失败，MUST NOT 自动使用本地 ASR 完成本次处理

#### Scenario: 临时密钥不可获取或已过期
- **WHEN** 密钥签发失败、密钥为空或 `expireAt` 已过期且刷新失败
- **THEN** 系统明确失败并保留可重试状态，MUST NOT 发起云端任务，也 MUST NOT 自动改用本地识别

### Requirement: 提供百炼异步文件转写
系统 SHALL 由客户端使用百炼文件转写 API 提交 `qwen3-asr-flash-filetrans` 任务，获取 `task_id` 后以有界间隔轮询任务状态；成功时 SHALL 将结果中的文本、句段时间范围和可用词级时间信息转换为统一 ASR 结果。任务 MUST NOT 由我们的服务端创建、轮询或对账。

#### Scenario: 云端任务成功
- **WHEN** 百炼任务状态变为 `SUCCEEDED` 且结果可下载或直接解析
- **THEN** 系统发布统一转写产物，保留源视频时间轴语义，并标记 provider 为 `aliyun`

#### Scenario: 云端任务失败或超时
- **WHEN** 百炼返回失败状态、不可解析结果或达到轮询/请求超时上限
- **THEN** 系统保存脱敏的失败原因并按冻结策略明确失败、保留可重试状态，MUST NOT 无限轮询，也 MUST NOT 自动转入本地 ASR

### Requirement: 为云端识别提供短期可访问音频
系统 SHALL 由客户端使用 `ai/llm-ak` 的短期 token 把标准音频直传百炼，并 SHALL 只使用百炼返回或按其要求构造的受控资源引用提交任务；系统 MUST NOT 将本地文件路径、`file://` URI 或永久公开 URL 直接提交给百炼。临时音频 SHALL 在任务结束、失败或取消后按生命周期清理。

#### Scenario: 临时音频 URL 可用
- **WHEN** 标准音频已按百炼要求上传并获得任务期间可访问的受控资源引用
- **THEN** 系统使用该引用提交百炼任务，并在云端任务完成、失败或取消后清理本地临时音频

#### Scenario: 无法生成受控 URL
- **WHEN** 上传失败、短期 token 不可用或无法构造受控资源引用
- **THEN** 系统不发起云端请求、记录脱敏原因并明确失败，MUST NOT 自动使用本地 ASR

#### Scenario: 音频超过云端单任务上限
- **WHEN** 完整来源音频超过百炼单任务处理上限
- **THEN** 系统按有重叠的固定区间分块，逐块直传并各自提交子任务，MUST NOT 删除静音后直接拼接

#### Scenario: 分块结果合并
- **WHEN** 同一来源音频的全部分块子任务返回结果
- **THEN** 系统把每块的块内时间还原为源视频时间，依据文本与时间交叠去重，并为合并后的句段分配稳定 ID

#### Scenario: 资源引用或短期 token 失效
- **WHEN** 资源引用已失效，或短期 token 在轮询中过期
- **THEN** 系统可重新上传或用新 token 重试一次；仍失败时明确失败并返回可区分的失效错误，MUST NOT 重复提交已成功付费的转写

### Requirement: 保护临时密钥和上游错误
系统 MUST 只在内存中保存短期 token、Authorization Header 与任务期间的资源引用，不得把短期凭据、认证头、完整音频 URL、签名下载地址或本地路径写入数据库、普通日志、诊断事件或前端状态；上游错误 SHALL 按 HTTP 状态、API code/message 和请求标识脱敏记录。

#### Scenario: 任务成功或终止
- **WHEN** 云端 ASR 任务成功、失败或取消
- **THEN** 系统释放内存中的短期 token 引用与资源引用，并确保持久化数据中不存在凭据、认证头或完整下载地址

#### Scenario: 百炼返回限流或鉴权错误
- **WHEN** 上游返回 401、403、429 或 5xx
- **THEN** 系统按可区分分类处理：鉴权与授权错误显式报告；限流与 5xx 在有界重试后明确失败并保留可重试状态，MUST NOT 自动回退本地，也不重复消耗授权

#### Scenario: 云端成功但清理失败
- **WHEN** 云端转写已成功发布，但本地临时音频清理失败
- **THEN** 系统保留已成功的转写结果、标记清理待重试，MUST NOT 因清理失败重新提交付费转写

### Requirement: 对云端和本地结果保持统一产物契约
系统 SHALL 将云端与本地识别结果写入相同的 ASR artifact/transcript 结构，并 SHALL 记录实际的 `provider`、模型、模型版本、分块策略与规范化版本，以及非敏感的失败原因。识别产物缓存键 SHALL 包含这些身份字段；旧产物 MUST 保持原有身份，MUST NOT 通过数据库迁移被改写为云端结果。

#### Scenario: 云端结果发布
- **WHEN** 云端转写结果通过统一校验
- **THEN** 系统按现有稳定句段 ID、源内时间戳和规范化规则发布结果，并记录真实的云端 `provider` 与模型身份

#### Scenario: 云端回退本地
- **WHEN** 云端路径失败且本地识别资源可用
- **THEN** 系统仍然明确失败并保留可重试状态，MUST NOT 自动改用本地 `whisper.cpp`，也 MUST NOT 用本地结果冒充云端结果（本场景名称沿用原规格，本变更后语义为“不再回退”）

#### Scenario: 用户显式选择本地识别
- **WHEN** 用户显式选择本地识别路径并执行一次识别
- **THEN** 系统使用本地 `whisper.cpp` 发布同一结构的结果，并记录真实的本地 `provider` 与模型身份

#### Scenario: 缺少时间范围、空文本或顺序异常
- **WHEN** 返回的句段存在越界时间范围、非空文本缺失或顺序错乱
- **THEN** 系统拒绝发布该结果并转入可区分的失败处理，不把未通过校验的句段写入工程

#### Scenario: 旧产物保持原身份
- **WHEN** 升级前已发布的本地转写产物在升级后被读取
- **THEN** 系统保持其原有 `provider` 与模型身份，不因新版本引入云端路径而改写或替换

## ADDED Requirements

### Requirement: 按客户端直连百炼的可用性优先使用云端 ASR
系统 SHALL 在开始一次 ASR 输入处理前分别确认百炼直连转写路径、可选本地识别路径与音频准备能力的可用性，并 SHALL 在云端路径可用时优先使用云端 ASR。授权与额度错误 MUST 显式报告并保留可区分的错误分类，MUST NOT 被描述为云端故障；临时网络与云端故障在有界重试后 MUST 明确失败并保留可重试状态，MUST NOT 自动回退本地；用户取消 MUST 直接终止且不回退。

#### Scenario: 云端路径可用
- **WHEN** heartbeat 表明账号已开通且额度可用，短期 token 可获取，百炼接口可达
- **THEN** 系统从客户端提交云端转写任务，并不启动本地识别作为首选路径

#### Scenario: 未开通或额度耗尽
- **WHEN** heartbeat 响应表明未开通，或 `llm-ak` 返回次数耗尽、时长额度耗尽的业务错误
- **THEN** 系统显示对应的中文授权或额度原因、保留可区分的错误分类，明确失败，MUST NOT 自动回退本地，也 MUST NOT 把它描述为云端故障

#### Scenario: 缺少本地转写模型但云端可用
- **WHEN** 本地 `whisper.cpp` 模型缺失或本地环境诊断失败，而百炼直连路径可用
- **THEN** 系统仍执行云端识别，不因本地模型缺失阻止或跳过云端路径

#### Scenario: 临时网络或云端故障
- **WHEN** 上传、任务创建或任务查询因网络超时、限流或上游 5xx 失败
- **THEN** 系统记录脱敏的瞬时故障原因，在有界重试后明确失败并保留可重试状态，MUST NOT 回退本地，也 MUST NOT 把该结果报告为授权或额度问题

#### Scenario: 用户取消
- **WHEN** 用户在云端转写进行中取消任务
- **THEN** 系统在本地有界终止、按上游能力请求取消，MUST NOT 回退本地，也 MUST NOT 把取消描述为云端故障

### Requirement: 本地幂等记录与待对账
系统 SHALL 在付费提交前于本地事务中持久化稳定的 `requestId`、任务类型、输入指纹与（若已取得的）上游 `task_id`。同一 `requestId` 与同一输入指纹 SHALL 复用原任务记录；同键不同输入 MUST 被拒绝。已提交但缺少 `task_id` 时 SHALL 进入待对账并先查询上游是否已创建，MUST NOT 自动再次提交付费请求。

#### Scenario: 提交后进程立即退出
- **WHEN** 系统已提交云端任务并在落盘后进程退出
- **THEN** 重启后系统按本地 `requestId` 找回原任务并继续，不重新提交付费请求

#### Scenario: 同键不同输入
- **WHEN** 同一 `requestId` 携带与落盘输入指纹不一致的输入再次提交
- **THEN** 系统拒绝该提交并返回可区分的冲突错误

#### Scenario: 待对账不自动重提交
- **WHEN** 本地记录显示已提交但缺少 `task_id`
- **THEN** 系统先查询上游是否已创建任务；在确认前 MUST NOT 自动再次提交付费请求
