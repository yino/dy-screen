## MODIFIED Requirements

### Requirement: 在剪辑工作台提供统一 AI 结果审阅栏
系统 SHALL 在当前剪辑会话保存最近一次一键 Agent、一键文本纠错以及增强方式选择与生成结果的可展示结果，并 SHALL 在任一工作流成功后自动打开右侧 AI 结果审阅栏。审阅栏 MUST 保持播放器和时间线可见，MUST 提供关闭和再次打开入口，并 MUST 在窄窗口切换为不造成内容溢出的覆盖式或全宽布局。审阅栏 SHALL 按高光展示最终唯一的增强方式、合成方式、参考图或视频资产的校验状态、降级原因与已产生成本。

#### Scenario: 工作流完成后自动审阅
- **WHEN** 一键 Agent 或一键文本纠错成功完成
- **THEN** 系统打开对应结果类型、展示本次计数与逐项列表，并保留轻量完成状态反馈

#### Scenario: 关闭后再次查看结果
- **WHEN** 用户关闭审阅栏但仍停留在当前剪辑会话
- **THEN** 顶栏提供带结果状态的再次打开入口，已有结果不会因关闭面板而丢失

#### Scenario: 离开剪辑会话
- **WHEN** 用户退出当前剪辑编辑器
- **THEN** 系统释放本次文本纠错审阅快照，不把字幕正文或差异另行写入持久化审计

#### Scenario: 重新打开已有 Agent 结果的工程
- **WHEN** 用户重新启动应用并打开存在已完成 Agent 运行和评分边界的工程
- **THEN** 属性栏恢复带数量的 AI 结果入口，并使用运行时冻结阈值展示最近一次 Agent 审阅

#### Scenario: 审阅增强方式与生成结果
- **WHEN** 智能任务完成增强阶段或其中某条高光发生降级
- **THEN** 系统按高光展示最终增强方式、合成方式、资产校验状态、降级原因与已产生成本，且不展示 Prompt 正文、资产下载地址或 Provider 原始响应

#### Scenario: 增强结果尚未就绪
- **WHEN** 用户打开审阅栏时部分高光的生成或渲染仍在进行
- **THEN** 系统按高光展示进行中状态并允许用户先审阅已就绪的结果，MUST NOT 因未就绪而阻塞整个审阅栏
