## Why

可用具体画面说明的场景、过程与故事无法用字幕表达，而这是 v2 相对于字幕分支的差异化能力。现有转场能力依赖本地目录中已提交的版本化素材（`assetKey + assetVersion`），受目录供给与人工编排限制，无法针对具体高光内容生成画面。本 change 引入**客户端直连万相**的生成式动画作为第三种媒体来源，并为每条高光提供互斥的 `video_animation` 增强方式。

生成能力不走我们的服务端：客户端 Rust 侧用既有的 `GET /api/client/ai/llm-ak` 短期 token 直连阿里云百炼，提交万相文生图与图生视频异步任务并轮询终态。万相的具体模型、参数、时长档位与结果下载方式**以 `validate-dashscope-direct-capabilities` 的探针结论为准**；当前已实测确认临时 token 可直接提交万相文生图与万相图生视频任务（http=200，返回 `task_id`）。

## What Changes

- 新增分镜与生成链路：Harness 生成有目标时长的分镜；客户端 Rust 侧据分镜直连万相提交参考图（文生图）与视频（图生视频）异步任务并轮询终态。每条高光只生成一段动画，参考图与视频各有独立的提交次数上限。
- 成功结果返回资产 ID、哈希、尺寸、帧率、实际时长与受控下载地址；客户端 MUST 校验下载文件与媒体属性后才允许应用。
- 本地幂等与门禁：付费提交前在本地事务中持久化稳定 `requestId`、任务类型与输入指纹，同键同输入复用、同键不同输入拒绝；任务级动画数量、累计秒数与金额上限在客户端本地冻结并校验，超限时 MUST NOT 提交。未开通与额度耗尽由上游业务错误码 3001 / 3003 / 3004 判定（heartbeat 响应不含额度字段）。
- 新增 `replace` 合成方式：使用生成画面替换高光内指定的源画面范围，保留连续的原视频音频与普通 ASR 字幕，工程总时长不变。
- 新增 `insert` 合成方式：作为独立时间轴单元增加工程时长，用于高光之间的桥接或章节转场；资产绑定稳定的左右片段 ID 与边界 ID，归属左侧高光，且在没有有效右侧片段时 MUST NOT 被选择。
- 时长适配规则：生成时长与目标范围的差异不超过 5% 时可以裁剪多余帧或受限变速，并保证最终偏差不超过一个输出帧；差异超过 5% 时该动画校验失败并进入字幕降级，MUST NOT 补黑帧或长时间冻结画面。
- `insert` 的生成音轨一律丢弃；客户端为插入段补齐 48 kHz 双声道静音，并在前后来源音频边界作受控的短淡出与淡入。桥接期间不显示来源 ASR 字幕，后续片段与其字幕随之顺延。
- 左右邻接关系改变后，该动画失效并需要重新审阅。
- 两种合成方式都 MUST NOT 叠加特效字幕。
- 降级：自动生成或媒体校验失败时，可在额度允许的情况下把该高光改为字幕分支；字幕分支也失败时保留普通原视频与基础字幕。每次降级 SHALL 记录最终唯一的 `enhancement.kind`、原因与成本，MUST NOT 让两条分支同时进入导出。
- 新增统一审阅契约：两种增强方式的生成结果与降级原因可在一处审阅。
- 历史兼容：历史工程继续按旧引用打开与导出；新工程改用生成式动画结果。本地目录素材的既有语义与已冻结引用不发生改变。
- 依赖探针：凡涉及生成能力、参数、时长档位、任务取消与资产下载的表述，均以 `validate-dashscope-direct-capabilities` 的探针结论为准。
- 非目标：不实现特效字幕路径本身（见 `add-effect-caption-renderer`）；不新增任何服务端接口，不使用 `image-jobs`/`video-jobs` 服务端任务接口或网关令牌；不向 Harness 暴露短期 token 或任意下载地址；不新增 `insert` 之外的时间线单元类型；不以生成音轨替代原声；不把生成式动画伪装为目录素材或新的 `renderMode`。

## Capabilities

### New Capabilities

- `ai-clip-generated-animation`: 生成式动画的分镜与资产契约、媒体校验、`replace` 与 `insert` 两种合成方式、时长适配、音频处理、邻接失效、失败降级与客户端门禁。

### Modified Capabilities

- `ai-clip-editor`: 白名单素材与属性扩展为包含已校验的生成式动画资产；安全导出新增从生成式动画资产读取媒体并处理静音补齐与边界淡化。
- `ai-transition-material-matching`: 明确生成式动画由独立生成契约约束、不属于“目录外素材”，并保持历史工程的目录素材选择语义不变。
- `ai-workflow-result-review`: 统一审阅栏扩展为覆盖两种增强方式的生成结果、降级原因与成本。

## Impact

- 客户端：`src-tauri/src/ai/repository.rs` 需新增生成资产、合成方式、邻接绑定与失效状态字段（当前最新迁移版本为 27，本 change 顺延）；`src-tauri/src/ai/clip_export.rs` 需支持 `replace` 的画面替换与 `insert` 的静音补齐与边界淡化；`src-tauri/src/transition_assets.rs` 的版本化资产下载与校验可作为生成资产的复用基础。
- 前端：`ui/src/AiWorkspace.tsx` 与 `ui/src/types.ts` 需要展示合成方式、生成状态、降级原因与审阅入口。
- 服务端依赖：**无新增接口**。仅复用 `GET /api/client/ai/llm-ak` 的短期 token 与 heartbeat 的开通/额度结论；生成调用由客户端直连万相，不经服务端中转。
- 成本：本 change 是唯一按次真金白银付费的能力，参考图与视频各有独立的提交次数上限，并受客户端冻结的任务级动画数量、累计秒数与金额上限约束；需要把成本与降级原因一并记录以便复核。
- 8 GB 目标设备：生成资产需下载、校验、解码并参与导出，需要测量峰值磁盘与导出耗时。
- 兼容：历史工程按旧引用打开与导出；生成式动画 MUST NOT 被写入目录素材表或伪装为新的 `renderMode`。
- 探针依赖：生成能力可用性、模型与参数取值、时长档位、任务取消语义与资产下载方式以 `validate-dashscope-direct-capabilities` 的探针结论为准。
