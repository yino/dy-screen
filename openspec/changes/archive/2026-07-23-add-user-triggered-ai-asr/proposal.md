## Why

当前“AI 剪辑”页面仍是占位页，用户无法把本地视频或某场直播的录像分片组织成一次分析任务，也无法获得后续高光识别和自动剪辑所需的带时间戳文本。现在录制、视频库和原始 MKV 分片已经稳定存在，可以在不影响录制链路的前提下补齐由用户主动发起的多视频本地 ASR 基础能力。

## What Changes

- 将“AI 剪辑”占位页改为可创建 AI 分析项目的工作区，但本变更只交付视频输入组织和语音转写，不交付高光判断或视频导出。
- 允许用户从本机导入多个视频，或选择一个已结束的直播会话并把其中全部可用的已完成分片展开为有序输入列表。
- 仅在用户确认输入列表并点击开始分析后创建任务；录像分片完成时不自动运行 ASR。
- 对每个输入视频使用 FFprobe 校验音轨，使用 FFmpeg 解码音频，并通过 VAD 跳过静音、挂机和纯背景音乐区域。
- 定义与具体模型无关的统一 `AsrEngine` 输入、输出、能力和错误契约；第一版通过 Rust `WhisperCppEngine` 适配器调用本地 `whisper.cpp` sidecar，生成带句段时间戳、文本和可选置信信息的中文转写。
- 在 AI 工作区按输入显示视频播放器与时间戳文本列表；点击文本可跳转到对应视频时间，播放时高亮并可跟随当前句段，播放器可选显示仅存在于 WebView 的临时字幕覆盖，不修改原视频。
- 支持复制当前视频或整个项目的文本，并导出保留稳定句段 ID、视频 ID 和时间范围的 TXT/JSON 文本产物。
- 按输入顺序合并多视频逻辑时间轴，保留单视频时间戳和项目内累计时间偏移，并对连续录制分片边界可能出现的重复文本去重；第一版不呈现可缩放、拖动或切割的图形化剪辑时间轴。
- 持久化项目、输入、任务状态、模型配置和转写片段，支持进度恢复、取消、失败重试和相同源版本的转写复用。
- 在单个输入缺少音轨、文件丢失或识别失败时隔离失败，不阻塞其他输入完成。
- 使用源路径、大小、修改时间和识别配置标识可复用结果；源文件变化或模型配置变化时不复用旧结果。
- 支持 macOS arm64 与 Windows x64 的本地识别基线；两个平台使用相同领域契约和模型格式，分别打包对应平台的 `whisper.cpp` 与 FFmpeg/FFprobe sidecar。
- 主安装包不携带多种语言运行时或多档大模型；第一版只分发当前使用的原生 sidecar、一个面向 8 GB 设备的 small 多语言量化模型及兼容 VAD 模型，安装后无需联网即可识别。
- 明确以下非目标：通用 Provider 插件协议、动态安装第三方 Provider、Python/Go/Node Provider、FunASR、云端 ASR、自动云端回退、在线模型下载、离线模型导入、多模型切换、实时 ASR、录像完成后自动识别、说话人分离、情绪与掌声等声音事件识别、人工编辑转写、SRT/ASS 字幕导出、图形化剪辑时间轴、NLP/LLM 高光评分、自动切片、字幕烧录和成品视频导出。

## Capabilities

### New Capabilities

- `ai-analysis-projects`: 定义用户在 AI 剪辑页面导入多个本地视频或选择已结束直播会话、整理有序输入、主动开始分析以及管理项目生命周期的行为。
- `local-speech-transcription`: 定义原始视频音轨探测、FFmpeg 音频解码、VAD、统一 `AsrEngine` 契约、首个 `whisper.cpp` 适配器、跨平台 sidecar 与模型准备、时间轴合并、结果复用、任务恢复和本地数据保护行为。

### Modified Capabilities

- `desktop-client-shell`: 将只展示规划说明且不得读取视频的 AI 剪辑占位页，改为可创建和管理本地 AI 分析项目的功能页面。

## Impact

- 前端：AI 剪辑页面、视频选择器、直播会话选择器、输入排序、任务进度、失败状态、可联动播放器、临时字幕覆盖、时间戳文本列表以及 TXT/JSON 复制与导出。
- Tauri 后端：新增 AI 项目命令、任务调度、事件发布、取消与恢复接口，并复用现有视频库查询、FFmpeg/FFprobe 配置和安全路径处理能力。
- Rust 核心：新增与具体供应商无关的 `AsrEngine` 契约、首个 `WhisperCppEngine` 适配器、媒体音频准备、VAD、转写合并和单并发后台工作队列；录制任务始终保持更高优先级。
- SQLite：新增 AI 项目、项目输入、ASR 产物、转写片段和模型配置相关数据，并保证删除项目不会删除原始视频。
- 本地运行环境：为 macOS arm64 和 Windows x64 分别提供 `whisper.cpp`、FFmpeg 与 FFprobe sidecar，并在两个安装包中包含相同版本的 small 多语言量化模型和 VAD 模型；任务前校验版本与完整性，正式分发处理平台签名、许可证及 Windows 原生运行库兼容。
- 隐私与网络：默认流程完全本地，不新增音视频上传、云端凭据或远程 AI 服务依赖。
