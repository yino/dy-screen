## Why

公开抖音直播页会根据客户端会话、JavaScript 执行环境和请求特征返回不同内容：真实浏览器可以正常观看时，当前无状态 `reqwest` resolver 仍可能得到 HTTP 200 的访问验证中间页，导致开播漏检、签名流地址无法刷新和录制中断。项目需要一个受控、可诊断的浏览器会话解析回退，在不自动绕过访问控制的前提下恢复公开直播间的稳定监听与续录。

## What Changes

- 新增全局持久化浏览器会话解析器，在原生 HTTP 通道被分类为 `access_restricted` 时切换到系统 WebView，并在同一浏览器上下文内提取公开直播页的受支持初始化数据。
- 浏览器会话优先静默完成标准页面脚本；只有页面要求用户交互时才进入“需要访问验证”状态，由用户主动打开受限验证窗口。
- 增加原生 HTTP、浏览器解析和用户验证之间的状态机、串行多房调度、会话失效恢复和有界快速通道试探。
- 调整直播间轮询节奏：全局公开页面访问间隔至少 5 秒，离线房间基础周期 60 秒并增加随机抖动，访问受限时停止密集原生 HTTP 重试。
- 扩充每次访问的控制台和 JSONL 诊断，记录请求通道、阶段、分类、HTTP 元信息、安全 marker、响应大小、耗时、失败次数、后续动作和重试时间，同时继续禁止记录 Cookie、页面正文和签名流地址。
- 在监控中心与设置页增加浏览器解析状态、访问验证提示、检查访问状态、立即验证和清除浏览器会话入口。
- 为直播间直连、个人主页接管、流地址失效续录、多房串行解析、验证窗口安全边界和日志脱敏增加自动化测试与真实公开直播间手工验收。
- 在打开 SQLite、执行 migration 或启动恢复前获取进程级独占锁，拒绝第二个桌面实例接管仍在运行的 worker 和录制会话。
- 将显式退出和系统 `SIGTERM`/`SIGINT` 统一接入幂等、有界的关闭流程，等待监听、FFmpeg、WebView、预览、缩略图和 AI 任务清理后再释放实例锁。
- 开发命令禁用会强制终止 Rust 父进程的 Tauri watcher，保留 Vite 前端热更新；Rust 改动必须安全停止旧实例后手动重启，避免无法接管的开发热重载遗留 FFmpeg。
- 为实例锁获取、二次启动拒绝、关闭原因、关闭完成和超时输出不含本地路径及敏感流地址的结构化控制台诊断。
- 自动验证码识别、行为模拟、代理池、第三方打码、账号自动登录、私有/付费内容和访问控制绕过不在本次范围内。

## Capabilities

### New Capabilities

- `browser-session-room-resolution`: 定义持久化系统 WebView 会话、浏览器内公开页面解析、访问验证生命周期、安全消息桥、串行调度和会话清理。

### Modified Capabilities

- `douyin-stream-discovery`: 增加原生 HTTP 与浏览器会话双通道解析、通道选择和一致的安全诊断约束。
- `streamer-monitoring`: 增加风控后的浏览器回退、轮询节奏、验证等待、录制续接和逐次访问结构化日志行为。
- `desktop-client-shell`: 增加全局访问状态、验证窗口、用户操作和本地会话隐私控制。

## Impact

- Rust/Tauri：新增浏览器会话服务、WebView 窗口管理、受限 IPC、resolver 编排和生命周期清理；调整 supervisor、状态 DTO、命令注册与日志模型。
- 桌面生命周期：新增应用数据目录独占锁和 Unix 终止信号处理，避免多实例启动恢复与父进程退出遗留 FFmpeg。
- 前端：增加访问状态横幅、验证与会话管理操作、浏览器演示降级以及对应状态文案。
- 数据：仅持久化非敏感诊断和通道状态；浏览器会话由平台 WebView 私有数据目录管理，不写入 SQLite 业务表或日志。
- 测试与工具：增加挑战页/受支持页 fixture、浏览器 resolver fake、状态机测试、日志脱敏测试、Makefile 聚焦目标和真实直播间诊断命令。
- 平台：第一阶段在 macOS 系统 WebView 完成真实验收，接口保持 Windows WebView2 和 Linux WebKitGTK 可扩展；不引入 Playwright/Chromium sidecar。
