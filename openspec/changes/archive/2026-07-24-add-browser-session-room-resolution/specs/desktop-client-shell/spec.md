## ADDED Requirements

### Requirement: 展示和管理公开页访问会话
系统 SHALL 在监控中心展示全局公开页访问状态，并 SHALL 在需要用户处理时提供非抢焦点横幅、系统通知、立即验证、重新检查和清除会话操作；浏览器演示模式 MUST NOT 伪造真实浏览器会话成功。

#### Scenario: 原生解析正常
- **WHEN** 当前公开页访问状态为 `native`
- **THEN** 界面不显示阻断横幅，主播继续展示各自直播与监听状态

#### Scenario: 浏览器正在回退解析
- **WHEN** 全局状态为 `browser_resolving`
- **THEN** 界面显示低干扰状态提示和当前待处理数量，不自动弹出或聚焦验证窗口

#### Scenario: 需要用户处理访问验证
- **WHEN** 全局状态为 `verification_required`
- **THEN** 界面显示持续横幅、最近脱敏原因和“立即验证”主操作，并发送一次去重系统通知

#### Scenario: 用户打开验证窗口
- **WHEN** 用户点击“立即验证”
- **THEN** 系统显示并聚焦受限抖音 WebView，保持当前待处理直播间页面和浏览器会话

#### Scenario: 用户重新检查
- **WHEN** 用户点击“检查访问状态”或在处理后触发立即检查
- **THEN** 系统先重试当前验证目标的原生通道，原生仍受限时才执行一次受控浏览器重新导航与有界探测，刷新全局状态，并在任一通道恢复后唤醒适用主播

#### Scenario: 用户清除会话
- **WHEN** 用户确认“清除抖音会话”
- **THEN** 界面等待后端完成 browsing data 清理，再显示 `session_expired` 和重新建立访问会话的操作

#### Scenario: 浏览器演示模式
- **WHEN** 用户在普通浏览器而不是 Tauri 中打开客户端
- **THEN** 页面显示真实访问验证仅桌面端可用，相关操作返回稳定不可用结果且不伪造直播状态

### Requirement: 约束验证窗口交互
系统 SHALL 让验证窗口只承载抖音官方公开页面，不显示客户端本地数据或通用命令，并 SHALL 在用户关闭窗口时隐藏而不是销毁持久会话。

#### Scenario: 验证窗口被关闭
- **WHEN** 用户点击窗口关闭按钮
- **THEN** 窗口隐藏、会话继续保留，主界面维持“需要访问验证”或最新探测状态

#### Scenario: 页面请求下载或外部新窗口
- **WHEN** 验证页面触发文件下载、非抖音导航或新窗口
- **THEN** 客户端拒绝请求且不调用系统打开、本地文件或主窗口 API

#### Scenario: 应用显式退出
- **WHEN** 用户显式退出客户端
- **THEN** 系统取消浏览器解析、关闭验证窗口并停止服务，但保留平台允许的持久会话供下次启动使用

### Requirement: 保证单实例拥有桌面运行状态
系统 MUST 在打开业务 SQLite、执行 migration 或启动恢复之前获取应用数据目录的进程级独占锁，MUST 由桌面状态持有锁至全部服务关闭，并 MUST NOT 允许第二实例修改仍由第一实例拥有的会话或启动重复 worker。

#### Scenario: 第一实例已经运行
- **WHEN** 用户或自动启动器尝试启动第二个桌面实例
- **THEN** 第二实例返回稳定的“应用已在运行”诊断并立即结束，且不打开业务数据库、不执行启动恢复、不创建 worker 或 FFmpeg

#### Scenario: 第一实例仍在关闭
- **WHEN** 第一实例已经开始关闭但尚未释放独占锁
- **THEN** 新实例继续被拒绝，不得提前把第一实例的活动会话标记为中断

#### Scenario: 第一实例完全退出
- **WHEN** 第一实例完成全部服务关闭并销毁桌面状态
- **THEN** 操作系统释放独占锁，后续单个实例可以正常获取锁、协调遗留文件并恢复已启用监听

### Requirement: 统一处理应用退出和系统终止信号
系统 SHALL 将前端确认退出、托盘退出、Tauri 退出请求以及 Unix `SIGTERM`/`SIGINT` 汇入同一个幂等、有界关闭流程，SHALL 等待后台服务和 FFmpeg 清理后再退出，并 SHALL 为关闭原因、完成或超时输出脱敏结构化控制台诊断。

#### Scenario: 多个退出来源同时触发
- **WHEN** 系统信号与应用退出事件在关闭期间重复到达
- **THEN** 只有第一个来源领取关闭流程，后续来源不得重复结束会话或重复释放资源

#### Scenario: 录制期间收到 SIGTERM
- **WHEN** 桌面进程正在录制且收到 `SIGTERM`
- **THEN** 系统取消 Supervisor 和录制任务，优先要求 FFmpeg 安全封装当前 MKV，在有界时间内完成会话协调并退出

#### Scenario: 子服务未在总期限内关闭
- **WHEN** 任一后台服务未在 20 秒总关闭期限内完成
- **THEN** 系统输出不含本地路径和敏感流地址的超时诊断并退出，不无限阻塞实例锁释放

#### Scenario: 开发期间修改 Rust 源码
- **WHEN** 开发者通过项目默认桌面开发命令运行客户端并修改 Rust 源码
- **THEN** Tauri 不自动强制结束旧应用，Vite 前端热更新继续可用，开发者必须安全停止旧实例后手动重启 Rust 应用
