## ADDED Requirements

### Requirement: 在剪辑工作台执行一键文本纠错
系统 SHALL 在字幕时间轴区域提供“一键文本纠错”命令，并 SHALL 在用户触发后调用本地 Rust 纠错工作流、显示当前阶段和进度、提供取消入口，并在成功后以返回的最新工程详情刷新字幕轨、预览字幕和右侧校对面板。运行期间系统 MUST 锁定会改变工程版本的字幕和片段操作，后端 MUST 独立执行相同竞态校验。

#### Scenario: 启动一键文本纠错
- **WHEN** 已激活用户在工程包含可纠错字幕且 DeepSeek 已配置时点击一键文本纠错
- **THEN** 按钮进入稳定运行状态，界面显示纠错进度和取消命令且不重复创建运行

#### Scenario: 文本纠错完成
- **WHEN** 后端原子保存纠错结果并返回最新工程
- **THEN** 工作台保持当前播放定位、刷新全部字幕视图并显示修改和跳过统计

#### Scenario: 文本纠错不可用
- **WHEN** 客户端未激活、Key 未配置、工程正在导出或没有可纠错字幕
- **THEN** 命令不可执行并显示具体原因，前端不调用 LLM

#### Scenario: 取消文本纠错
- **WHEN** 用户点击运行状态中的取消命令
- **THEN** 工作台请求取消、等待后端终态并保持当前工程字幕不变

### Requirement: 在剪辑工作台执行两阶段一键 Agent
系统 SHALL 在紧凑顶栏提供“一键 Agent”命令，并 SHALL 展示匹配中、评分中、应用中、已完成、已取消和失败状态，提供取消入口，在终态刷新边界、转场时间轴单元与属性面板。界面 SHALL 展示当前运行冻结阈值及已应用、仅建议、无需转场、跳过和失败数量，不得把低分建议描述为已应用。

#### Scenario: 启动一键 Agent
- **WHEN** 已激活用户在 DeepSeek 已配置、素材目录可用且工程存在未锁定有效边界时点击一键 Agent
- **THEN** 工作台创建一次两阶段运行、冻结当前阈值并防止重复启动

#### Scenario: Agent 达到阈值
- **WHEN** 后端返回一个达到冻结阈值且已自动应用的边界结果
- **THEN** 时间轴显示对应转场准备状态，属性面板展示 0–10 总分、评分维度和理由

#### Scenario: Agent 低于阈值
- **WHEN** 后端返回低于冻结阈值的最佳建议
- **THEN** 工作台展示低分建议和理由，但时间轴不插入该素材

#### Scenario: 一键 Agent 不可用
- **WHEN** 客户端未激活、Key 未配置、素材目录为空或工程没有可匹配边界
- **THEN** 命令不可执行并显示具体原因，前端不创建运行

#### Scenario: 取消一键 Agent
- **WHEN** 用户在匹配、评分或应用阶段点击取消
- **THEN** 工作台请求取消、停止后续阶段并刷新后端确认的最终边界状态
