## ADDED Requirements

### Requirement: 为主播维护多个有序标签
系统 SHALL 允许每个主播维护最多 10 个按优先级排序的本地标签；每个标签 MUST 包含名称，并 MAY 包含供未来切片上下文使用的 Prompt 指导，但本能力 MUST NOT 生成 Prompt 或调用 LLM。

#### Scenario: 保存多个主播标签
- **WHEN** 用户为主播保存“带货”和“搞笑”等多个有效标签
- **THEN** 系统按用户指定顺序持久化标签，并在后续查询中返回相同顺序

#### Scenario: 保存只有名称的标签
- **WHEN** 用户填写有效标签名称但没有填写 Prompt 指导
- **THEN** 系统允许保存该标签，并把 Prompt 指导表示为空值

#### Scenario: 超过标签数量限制
- **WHEN** 用户尝试为同一主播保存超过 10 个标签
- **THEN** 系统拒绝本次更新并返回标签字段的中文校验错误，原标签集合保持不变

### Requirement: 校验并规范化标签内容
系统 SHALL 去除标签名称和 Prompt 指导的首尾空白，标签名称 MUST 为 1–24 个字符，Prompt 指导 MUST 不超过 500 个字符，并 MUST 拒绝空名称、控制字符和同一主播内规范化后重复的名称。

#### Scenario: 同一主播提交重复标签
- **WHEN** 用户提交的两个标签名称仅在大小写或首尾空白上不同
- **THEN** 系统将它们识别为重复标签并拒绝保存，不静默丢弃任意一项

#### Scenario: 标签名称或指导过长
- **WHEN** 标签名称超过 24 个字符或 Prompt 指导超过 500 个字符
- **THEN** 系统返回稳定错误码和中文字段错误，不写入部分标签

#### Scenario: 标签包含控制字符
- **WHEN** 标签名称或 Prompt 指导包含不允许的控制字符
- **THEN** 系统拒绝该标签，且错误输出不回显未经处理的完整内容

### Requirement: 使用关系模型持久化标签
系统 SHALL 使用与主播关联的关系记录持久化标签名称、规范化名称、可选 Prompt 指导和排序位置，并 SHALL 保证同一主播的规范化标签名称唯一。

#### Scenario: 升级已有数据库
- **WHEN** 应用首次打开尚未包含主播标签表的现有 SQLite 数据库
- **THEN** migration 创建标签表、唯一索引和级联外键，所有已有主播获得空标签集合，现有主播、会话和视频关系保持不变

#### Scenario: 原子替换标签集合
- **WHEN** 用户保存主播的新标签集合
- **THEN** 系统在同一事务中完成校验、删除旧关联和写入新顺序，失败时恢复完整旧集合

### Requirement: 提供未来切片使用的结构化标签上下文
系统 SHALL 提供只读、确定性排序且可序列化的 `StreamerPromptContext`，包含主播内部 ID、主播名称以及标签名称、可选 Prompt 指导和优先级；该上下文仅作为未来 Prompt 构建输入，MUST NOT 在本变更中触发模型调用。

#### Scenario: 读取带货搞笑主播的上下文
- **WHEN** 主播标签依次为“带货”和“搞笑”
- **THEN** 系统返回包含两个标签及其优先级的结构化上下文，使未来切片逻辑能够重点寻找商品表达和搞笑表达相关句子

#### Scenario: 主播没有标签
- **WHEN** 请求没有任何标签的主播上下文
- **THEN** 系统返回空标签数组而不是错误、默认标签或自动推断结果

#### Scenario: 标签内容进入未来 Prompt
- **WHEN** 后续功能使用 `StreamerPromptContext` 构建 Prompt
- **THEN** 标签内容必须作为明确分隔的用户配置数据处理，不得覆盖系统安全规则、输出格式或模型调用约束

### Requirement: 保持标签完全本地和用户可控
系统 SHALL 只在本地 SQLite 和本地界面中处理主播标签，MUST NOT 自动从主页、转写文本或外部模型推断标签，也 MUST NOT 自动上传标签。

#### Scenario: 新增主播但用户没有填写标签
- **WHEN** 用户添加主播且没有配置标签
- **THEN** 系统保存空标签集合，不发起额外网络请求或模型调用

#### Scenario: 编辑标签
- **WHEN** 用户手动修改标签名称、指导或顺序
- **THEN** 系统只保存用户明确提交的结果，不自动改写或补充标签
