## MODIFIED Requirements

### Requirement: 从本地目录构建受限匹配上下文
系统 SHALL 只从当前剪辑工程相邻精彩片段、主播标签和本地已提交素材目录构建匹配上下文。每个边界的输入 MUST 仅包含前一片段尾部和后一片段头部的有界 ASR、素材键与版本、标题、描述、标签和分类；MUST NOT 包含下载 URL、本地路径、Cookie、激活码、设备 ID、视频或音频。匹配可由用户显式启动，或由已授权智能成片任务在自动化拥有的草稿上启动；自动启动 MUST 使用同一上下文、目录和本地校验边界。

#### Scenario: 为相邻精彩构建候选
- **WHEN** 用户对包含两个或更多片段的工程启动智能匹配
- **THEN** Rust 为每个未人工锁定的有效边界生成有界语义上下文，并从当前本地目录确定性召回有界素材候选

#### Scenario: 智能任务为相邻精彩构建候选
- **WHEN** 已授权智能任务的自动化草稿完成字幕阶段且存在未人工锁定的有效边界
- **THEN** Rust 编排器按任务和草稿代次创建一次两阶段运行，并使用既有目录确定性召回候选

#### Scenario: 工程只有一个片段
- **WHEN** 工程不存在相邻片段边界
- **THEN** 系统不调用 LLM，并将当前工程标记为无需匹配转场而不是使智能流水线失败

#### Scenario: 本地目录不可用
- **WHEN** 没有已提交目录或当前目录没有受支持的 `bridge` 素材
- **THEN** 系统不调用 LLM，保留工程不变并提供同步素材目录的入口；智能任务进入可审阅但转场未完成状态

### Requirement: 持久化两阶段运行进度与脱敏审计
系统 SHALL 为一键 Agent 持久化运行 ID、工程版本、冻结阈值、模型、匹配与评分 prompt 版本、阶段、边界计数、token 用量、素材键版本、评分维度、理由和脱敏错误分类，并 SHALL 向工作台发布匹配中、评分中、应用中、已完成、已取消或失败进度。由智能成片编排器创建的运行还 MUST 保存智能任务 ID、草稿代次、阶段尝试代次和输入指纹，并在结果应用前验证这些代次仍是当前值。系统 MUST NOT 保存 API Key、完整 Prompt、原始 Provider 响应、隐藏推理、本地路径、视频或音频。

#### Scenario: 两阶段运行完成
- **WHEN** 全部目标边界已经完成匹配、评分和条件应用
- **THEN** 工作台刷新工程边界并显示已应用、仅建议、无需转场、跳过和失败数量，智能任务同步更新对应阶段终态

#### Scenario: 运行在应用重启后中断
- **WHEN** 用户显式创建的一键 Agent 运行未到终态且客户端异常退出
- **THEN** 系统把运行恢复为可诊断的中断状态且不自动重发 LLM 请求或改变工程

#### Scenario: 智能任务运行在应用重启后中断
- **WHEN** 智能任务创建的两阶段运行未到终态且客户端异常退出
- **THEN** 系统把旧尝试标记中断，在重新验证激活、授权、草稿代次和输入指纹后允许父任务创建新尝试，并忽略旧响应

#### Scenario: 自动应用前草稿所有权变化
- **WHEN** 两阶段运行期间用户修改工程、锁定边界或草稿切换为用户拥有
- **THEN** 系统不得自动覆盖变化边界，保留合法评分为建议并向父任务报告冲突或跳过数量

## ADDED Requirements

### Requirement: 智能任务复用现有两阶段匹配而非整片模板
系统 SHALL 将智能成片中的“一键 Agent”解释为复用现有场景匹配 Agent、评分 Agent 和版本化 `bridge` 素材目录。系统 MUST 继续按运行冻结的默认 8 分或用户已保存阈值自动应用高分结果，并 MUST 仅展示低分结果；系统 MUST NOT 选择整片模板、任意远程 URL、BGM、封面、发布文案或目录外素材。

#### Scenario: 智能草稿匹配高分素材
- **WHEN** 自动运行的最佳合法目录候选达到冻结阈值且边界仍未锁定
- **THEN** 系统按既有规则固定素材键和版本、触发按需下载并标记选择来源为自动

#### Scenario: 智能草稿只有低分建议
- **WHEN** 自动运行的最佳合法目录候选低于冻结阈值
- **THEN** 系统保留评分和理由供审阅，不向时间轴插入素材且仍允许草稿进入可审阅状态

#### Scenario: Provider 返回整片模板或目录外素材
- **WHEN** 任一响应引用目录外素材、整片模板、URL、BGM 或其他未授权生成物
- **THEN** Rust 拒绝该结果、记录脱敏校验错误且不修改工程
