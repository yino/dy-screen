## Why

一键 Agent 与一键文本纠错已经能完成后台处理，但完成后只显示计数汇总，逐边界评分和逐字幕差异缺少可发现、可定位、可操作的审阅入口。用户无法判断 Agent 为什么给出建议，也难以确认文本实际改了什么，导致结果无法直接用于剪辑决策。

## What Changes

- 在剪辑工作台右侧增加可展开的 AI 结果审阅栏，并在工作流完成后自动打开对应结果。
- 为一键 Agent 展示本次阈值、结果分类、边界上下文、建议素材、总分、四项评分维度和理由。
- 为低分建议提供预览、应用建议和定位时间线操作，为已应用与无需转场结果提供明确状态。
- 为一键文本纠错展示本次修改、未变化和跳过统计，并按字幕展示 ASR 原文与纠错结果的字符级差异。
- 将结果行与播放器、时间线、边界和字幕属性同步；关闭审阅栏后提供明确的再次打开入口与时间线标记。
- 当前会话继续保留完整文本纠错差异；最近一次 Agent 结果可从既有运行审计与边界评分恢复，不新增包含字幕正文的审计持久化。

## Capabilities

### New Capabilities

- `ai-workflow-result-review`: 定义一键 Agent 与一键文本纠错完成后的结果审阅、筛选、差异展示、时间线定位和可用操作。

### Modified Capabilities

无。

## Impact

- 前端：扩展剪辑工作台的工作流结果状态、右侧审阅栏、时间线标记、字符差异渲染和响应式布局。
- API：继续使用现有 `TransitionMatchSummary` 与 `ClipTextCorrectionSummary.detail`，增加只读的最近一次 Agent 审阅 command，不增加数据库迁移。
- 测试：增加 Agent 评分明细、文本差异、筛选、自动打开、重新进入、时间线定位和建议应用测试。
- 非目标：不提供多次运行历史，不跨重启恢复文本纠错正文差异，不改变文本纠错原子提交规则，不保存新的字幕正文副本，不批量强制应用低于阈值的建议。
