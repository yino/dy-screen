## Why

当前剪辑工作台只有固定枚举的淡入、淡出等单片段效果，无法使用服务端持续更新的反应桥接视频，也无法根据相邻精彩文案自动选择合适素材。服务端现已通过授权心跳发布素材目录版本，并提供带描述、标签、媒体元数据和 SHA-256 的全量目录接口，需要在客户端建立可离线读取、可校验下载、可人工覆盖且能安全导出的完整链路。

## What Changes

- 将客户端版本从 `0.2.0` 升级为 `0.3.0`，满足服务端素材目录声明的最低应用版本。
- 扩展现有授权心跳契约，读取可选 `transitionMaterials.catalogVersion` 和 `minimumAppVersion`，只把版本变化发布给独立素材同步任务，不让素材同步失败改变授权状态。
- 对接 `GET /api/v1/transition-materials?clientVersion=<version>`，复用激活设备请求头，严格解析业务信封、目录版本和全量素材；正式环境只接受 HTTPS，并将完整 URL 限制到受信 CDN 同源，兼容未来相对路径响应。
- 在本地 SQLite 保存目录版本、素材元数据和下载状态；版本不一致时事务化全量同步，保留已下载或历史工程仍引用的旧素材，不把目录同步等同于全量视频下载。
- 在应用数据目录按 `assetKey + assetVersion` 按需下载素材，校验声明大小和 SHA-256，使用临时文件原子发布并支持失败重试；LLM 选中、用户预览或手动应用时才触发下载。
- 把服务端 `renderMode=bridge` 素材作为带原声的完整桥接视频插入两个相邻精彩片段之间；它增加工程总时长，桥接期间不显示来源 ASR 字幕，并通过受控 FFmpeg 管线规范化画幅、音视频和最终 H.264/AAC MP4。
- 对 HEVC 等 WebView 不兼容素材复用受控 FFmpeg 生成本地 H.264 预览缓存；服务端逐步统一 H.264 作为优化，但客户端不得依赖该假设跳过媒体检查。
- 增加受限的转场素材匹配 Agent：Rust 从本地目录读取候选，把相邻片段末尾/开头 ASR、主播标签和素材描述作为有界数据交给当前 DeepSeek Provider；Agent 只返回 `assetKey`、版本、`none`、置信度和理由。
- 置信度达到 `0.75` 的有效匹配自动加入剪辑草稿，低置信度结果只作为建议；用户手动选择会锁定该边界，后续 Agent 不得覆盖。
- 在剪辑工作台素材库展示远程目录、缩略图、下载/失败/已就绪状态，支持搜索、预览、手动应用、替换、移除和重新智能匹配；片段重排或删除只使受影响的自动匹配失效，不自动调用 LLM。
- **BREAKING**：剪辑工程总时长、字幕工程时间和导出计划不再只由原始精彩片段组成，还必须计入已应用桥接素材；相关 DTO、SQLite schema 和导出计划需要升级。
- 第一版不支持用户导入本地素材、透明叠加素材、遮罩素材、真正的 `xfade`、素材商店、账号云同步或启动时下载整个素材库。

## Capabilities

### New Capabilities

- `transition-material-catalog`：定义授权目录版本发现、全量 SQLite 同步、受信 URL 校验、按需下载、完整性检查、缓存保留和素材预览状态。
- `ai-transition-material-matching`：定义基于相邻 ASR 和本地素材描述的受限 Agent 匹配、结构化结果校验、置信度自动应用、人工锁定及失效重匹配。

### Modified Capabilities

- `client-activation-service`：心跳成功响应可携带素材目录版本和最低客户端版本，并在不耦合授权结果的前提下触发素材同步信号。
- `ai-clip-editor`：剪辑工程、时间轴、字幕映射、素材库、预览和导出需要支持位于相邻精彩片段之间的版本化桥接视频及其原声。

## Impact

- Tauri/Rust：`api.rs`、`activation.rs`、应用生命周期、SQLite migrations/repository、AI LLM 契约、素材下载器、预览服务和剪辑导出计划。
- React：剪辑素材库、素材搜索/缩略图/下载状态、边界建议、手动锁定、时间轴桥接片段和重匹配交互。
- 服务端契约：现有心跳 `transitionMaterials` 字段和 `/api/v1/transition-materials` 全量响应；不新增客户端可提交的任意 URL。
- 本地存储：新增目录状态、版本化素材、下载状态、匹配运行和工程边界选择；媒体文件写入应用数据目录而非 SQLite。
- 发行：同步更新 npm、Cargo、Tauri 配置和锁文件中的客户端版本为 `0.3.0`，扩展 macOS/Windows FFmpeg 能力审计以覆盖 H.264/HEVC 解码和桥接导出。
- 安全与隐私：激活码、设备 ID 和完整本地路径仍只留在 Rust；LLM 不接收下载 URL、本地路径、Cookie、视频或音频，服务端素材必须具有客户端剪辑和导出许可。
