# AI 工作流结果审阅规格

## Purpose

定义一键 Agent 与一键文本纠错完成后的统一结果审阅、筛选、差异展示、时间线定位和可用操作，并约束重启恢复、人工锁定以及字幕正文不持久化的边界。

## Requirements

### Requirement: 在剪辑工作台提供统一 AI 结果审阅栏
系统 SHALL 在当前剪辑会话保存最近一次一键 Agent 和一键文本纠错的可展示结果，并 SHALL 在任一工作流成功后自动打开右侧 AI 结果审阅栏。审阅栏 MUST 保持播放器和时间线可见，MUST 提供关闭和再次打开入口，并 MUST 在窄窗口切换为不造成内容溢出的覆盖式或全宽布局。

#### Scenario: 工作流完成后自动审阅
- **WHEN** 一键 Agent 或一键文本纠错成功完成
- **THEN** 系统打开对应结果类型、展示本次计数与逐项列表，并保留轻量完成状态反馈

#### Scenario: 关闭后再次查看结果
- **WHEN** 用户关闭审阅栏但仍停留在当前剪辑会话
- **THEN** 顶栏提供带结果状态的再次打开入口，已有结果不会因关闭面板而丢失

#### Scenario: 离开剪辑会话
- **WHEN** 用户退出当前剪辑编辑器
- **THEN** 系统释放本次文本纠错审阅快照，不把字幕正文或差异另行写入持久化审计

#### Scenario: 重新打开已有 Agent 结果的工程
- **WHEN** 用户重新启动应用并打开存在已完成 Agent 运行和评分边界的工程
- **THEN** 属性栏恢复带数量的 AI 结果入口，并使用运行时冻结阈值展示最近一次 Agent 审阅

### Requirement: 审阅一键 Agent 的逐边界评分
系统 SHALL 对本次 Agent 返回的边界按已应用、待确认和无需转场分类，并 SHALL 展示运行阈值、左右片段上下文、素材标题、0–10 总分、场景适配、前后衔接、节奏匹配、素材契合及评分理由。系统 MUST 把低于阈值的合法建议描述为待确认或未应用，不得描述为已应用。

#### Scenario: 查看低分建议
- **WHEN** 本次边界存在低于冻结阈值的最佳合法候选
- **THEN** 审阅栏默认突出该待确认结果，展示总分、四项评分、理由和“低于阈值，未应用”状态

#### Scenario: 查看自动应用结果
- **WHEN** 本次边界的合法候选达到冻结阈值并已自动应用
- **THEN** 审阅栏以已应用状态展示实际素材、评分和理由，不要求用户再次应用

#### Scenario: 查看无需转场结果
- **WHEN** Agent 为边界返回无需转场建议
- **THEN** 审阅栏明确显示“无需转场”，不虚构素材标题或评分

#### Scenario: 从结果定位边界
- **WHEN** 用户选择一个 Agent 结果
- **THEN** 系统选中相同边界、将播放头定位到该边界并同步高亮结果行和时间线标记

#### Scenario: 处理低分建议
- **WHEN** 用户在待确认结果中选择预览或应用建议
- **THEN** 系统复用受信素材预览或应用路径，并在成功后刷新工程边界和当前审阅状态

#### Scenario: 所有边界均已人工锁定
- **WHEN** 一键 Agent 因没有未锁定边界而不可执行且工程存在最近一次 Agent 结果
- **THEN** 系统保留结果审阅入口、说明锁定原因，并允许用户在审阅项中解除指定边界的人工锁后再次运行

### Requirement: 审阅一键文本纠错的本次差异
系统 SHALL 在启动文本纠错前保存当前会话字幕文本快照，并 SHALL 在成功后按字幕 ID 比较返回工程，只把本次实际变化的字幕列为已修改。每项 MUST 展示片段、工程时间、ASR 原文、纠错结果和字符级新增/删除差异；既有人工修改、隐藏字幕和未变化字幕 MUST NOT 混入本次已修改列表。

#### Scenario: 查看纠错差异
- **WHEN** 一键文本纠错修改一条或多条字幕
- **THEN** 审阅栏默认显示已修改项，并以文字标签和差异样式同时标出纠错前后内容

#### Scenario: 没有文本变化
- **WHEN** 文本纠错成功但所有已处理字幕均未变化
- **THEN** 审阅栏显示本次没有修改，并继续展示处理、未变化和跳过统计

#### Scenario: 从差异定位字幕
- **WHEN** 用户选择一条纠错差异
- **THEN** 系统切换到字幕属性、选择相同字幕并把播放器和时间线定位到字幕开始时间

#### Scenario: 恢复单条 ASR 原文
- **WHEN** 用户在纠错差异中点击恢复 ASR 原文
- **THEN** 系统复用现有工程版本校验和字幕恢复命令，成功后刷新工程与审阅状态，失败时保留差异并显示可重试原因

### Requirement: 通过筛选和时间线标记保持结果可发现
系统 SHALL 为 Agent 结果提供全部、已应用、待确认和无需转场筛选，为文本纠错提供已修改、未变化和已跳过统计筛选或状态视图。当前会话中有结果的边界和字幕 MUST 在时间线显示稳定且不改变轨道尺寸的语义标记，标记 MUST 能打开相应审阅结果。

#### Scenario: 筛选 Agent 结果
- **WHEN** 用户选择已应用、待确认或无需转场筛选
- **THEN** 审阅栏只显示相应本次结果并保持当前播放器位置，除非用户显式选择结果行

#### Scenario: 点击时间线结果标记
- **WHEN** 用户点击带有本次 Agent 分数或文本纠错状态的时间线单元
- **THEN** 系统打开对应审阅类型、选择该结果并保持列表与时间线选择同步

#### Scenario: 结果状态不只依赖颜色
- **WHEN** 系统显示评分、应用状态或文本新增删除
- **THEN** 每种状态同时具有可读文字、数值、图标或文本装饰，辅助技术可读取其含义
