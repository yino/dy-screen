# 切片智能体 Wiki

本文档集面向产品使用、开发维护和发行验收。当前客户端提供直播监听与录制、智能成片与边播边剪、
本地 ASR、用户授权的 DeepSeek 高光分析、应用内视频预览、客户端激活和抖音公开页访问恢复。

## 当前处理链路

```text
公开主页/直播间
       ↓
直播状态解析 → FFmpeg 录制 → MKV 分片 → 视频库/应用内预览
                                      ↓
本地视频或正在录制的受信直播会话
       ↓ 用户创建智能任务并确认一次授权
完整分片 → 本地 ASR → 高光提取 → 优秀候选入选
       ↓
合辑草稿 → 工程字幕纠错 → 转场匹配 → 人工审阅 → 显式导出
```

普通 AI 项目不会自动开始 ASR 或高光分析。只有用户明确创建并授权的智能任务会自动推进到可审阅
草稿；它仍不会自动选择输出路径、导出或发布视频。

## 使用入口

### 普通用户

1. 启动客户端并完成客户端激活。
2. 等待随包运行资源后台校验完成；资源损坏或缺失时按界面提示下载。
3. 在监控中心添加公开主页或直播间，必要时人工完成抖音访问验证。
4. 在视频库预览已结束分片，或在 AI 剪辑中导入多个视频。
5. 在智能成片中选择本地视频，或从“直播素材”选择直播回放、正在直播，确认当前任务授权并等待
   可审阅草稿；也可在高级模式中继续使用普通项目的手动 ASR 和高光流程。

### 开发者

```bash
make app-dev DY_SCREEN_API_BASE_URL="http://localhost/api/"
```

默认开发命令使用 `tauri dev --no-watch`。React 仍可热更新，但 Rust 修改后必须安全停止旧进程并
重新运行命令。不要同时启动第二个桌面实例；应用数据目录的进程锁会拒绝它。

### 发行维护者

发行构建必须同时固定应用版本、授权服务地址、Runtime Resource Pack 地址、资源 manifest、
签名和第三方许可证。资源下载地址不是用户设置，前端也不能传入 FFmpeg、Whisper 或模型路径。

## 安全与隐私边界

- 录像、ASR 产物、高光结构化结果和用户选择默认保存在本机。
- 本地 ASR 不上传视频、音频或文本。
- 高光分析只在用户确认后发送规范化文本、稳定句段 ID、相对时间、标签和分析目标。
- 智能任务授权只覆盖当前任务或直播场次，不扩散到普通项目；直播模式只消费完成登记的分片。
- 智能任务不会自动导出或发布，人工编辑和导出冻结后的新高光进入下一版草稿。
- DeepSeek API Key 保存到操作系统凭据库，不写入 SQLite、日志、事件或前端状态。
- 抖音验证 WebView 只允许受信 HTTPS 页面，不向远程页面开放主窗口命令或本地文件权限。
- 授权服务埋点只接受白名单字段，不上传媒体、ASR 文本、Cookie、本地路径或页面正文。

## 文档维护规则

功能行为以 `openspec/specs/` 和当前代码为准；Wiki 负责说明用户操作、运行机制、故障处理和验收
入口。每次影响用户流程、持久化状态、安全边界、发行资源或恢复行为的提交，都应同步更新对应
专题页和 [最近变更](最近变更.md)。仍需真实设备或外部服务验证的内容必须明确标为未完成。
