## 当前用户流程变化

### 启动

旧流程会在桌面 `setup` 阶段同步、重复读取大模型和运行资源计算 SHA-256，窗口可能长时间没有
响应。`fca4521` 之后窗口先显示 `verifying`，完整校验只在后台执行一次；校验成功后热激活
ASR 和媒体工具，再恢复业务任务。

### AI 项目

ASR 项目仍然只由用户创建和启动。用户可以导入多个本地视频，或选择一场已经结束的直播并一次
加入所有登记分片。主播正在新一场直播不影响选择其历史已结束会话；当前仍写入的会话不可导入。

### 高光分析

高光分析不再是一次请求后只能等待页面结果的临时动作。运行和批次保存在 SQLite，界面主动查询
进度；切换菜单不会中断，重启后可从完整阶段继续。候选现在与真实 ASR 句段、来源视频和播放器
联动，用户的“加入待切片”选择即时保存。

### 授权与访问

客户端激活和抖音访问验证是两套独立状态：前者控制是否允许业务运行，后者只决定公开直播页能否
解析。临时心跳网络错误进入 `retrying`，明确停用/过期/解绑才暂停后台任务。抖音访问恢复后只
唤醒一次等待 worker，不会反复导航。

### 视频预览

预览仍是按需生成的可清理 MP4。竖屏视频使用完整包含展示；高光“播放片段”只限制播放器起止
时间。最新修复为 FFmpeg 临时 MP4 显式指定 MOV muxer 和 `mp42` brand，降低 Tauri WebView
拒绝兼容预览的概率。

## 回归检查

维护上述能力时至少执行：

```bash
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo test --manifest-path src-tauri/Cargo.toml --test runtime_resource_state --test preview
npm test -- --run ui/src/App.test.tsx ui/src/AiWorkspace.test.tsx
npm run typecheck
git diff --check
```

涉及真实 FFmpeg、Whisper、DeepSeek、客户端授权服务、抖音 WebView 或正式安装包时，还必须在对应
外部环境执行验收；仓库 mock、fixture 和交叉编译不能替代真实服务、真实媒体或目标机证据。
