# 智能成片与边播边剪

“智能成片”把 ASR、高光提取、工程字幕纠错和转场素材匹配编排成一个可恢复任务。它支持本地
视频和正在录制的直播间，但不会自动导出或发布视频。

## 两种模式

### 本地视频

1. 在“AI 剪辑 > 智能成片”选择“本地视频”。
2. 使用系统文件选择器选择一个或多个视频；界面按选择顺序显示来源摘要。
3. 核对 Provider、模型、发送范围和输出目标，确认一次当前任务授权。
4. 系统依次执行本地 ASR、高光提取、优秀候选入选、合辑草稿、工程字幕纠错和转场匹配。
5. 打开“审阅成片”，检查片段、字幕和转场建议，再明确选择目标并导出 MP4。

### 自动直播剪辑

1. 先在监控中心让公开直播间进入录制状态。
2. 在智能成片中选择“直播间”；列表只显示系统已监听且正在录制的受信会话，没有 URL 输入。
3. 确认一次当前直播场次授权。授权不会用于其他直播、其他智能任务或普通 AI 项目。
4. recorder 完成封装并登记一个不可变分片后，系统才把它加入 ASR 队列。正在写入的文件不会
   被读取、探测或识别。
5. 新的唯一优秀高光会更新仍由自动化拥有的草稿；人工编辑或开始导出后，新高光进入下一版。
6. 直播结束后系统处理已经登记的剩余分片。失败批次会保留，并允许从失败阶段重试。

## 授权与发送范围

一次授权包含当前来源、成片目标、输出偏好、Provider、模型和最小文本范围。云端阶段只接收入选
片段需要的规范化字幕或工程字幕副本；视频、音频、本地路径、API Key、完整 Prompt 和原始响应
不会作为任务授权内容发送或写入事件。

来源、Provider、模型或文本范围改变后，旧授权失效。普通 AI 项目继续要求用户显式启动高光，
不会继承智能任务授权。

## 候选、草稿和导出

- 合格候选保留供审阅；达到运行冻结的优秀阈值后自动入选。
- 没有优秀候选时任务进入候选审阅，不创建空工程。
- 相邻完整直播分片可以提供有限只读上下文；候选仍必须映射回真实句段和已登记源内时间。
- 重复高光按稳定句段、会话时间和语义指纹合并；真实跨分片内容保留多个连续来源片段。
- “自动更新中”表示当前草稿仍可接收新高光；“已转为人工编辑”表示当前版本不再自动覆盖。
- “导出已冻结”表示来源、片段、字幕和转场计划已固定。导出期间的新高光进入下一版草稿。
- 导出始终由用户选择目标并点击“导出 MP4”，系统不会静默导出或自动发布。

## 恢复与故障处理

页面挂载和应用重启后会先查询 SQLite 快照，再订阅后续事件。成功且输入指纹未变化的阶段会复用；
失败或中断阶段创建新的尝试代次，旧事件和迟到 Provider 响应不能覆盖当前草稿。

| 现象 | 处理方式 |
| --- | --- |
| 创建按钮不可用 | 检查客户端激活、Runtime Resource Pack、Provider Key、受信来源和授权复选框 |
| 直播列表为空 | 确认监控中心正在录制；已结束、未监听和私有来源不会出现 |
| 显示处理积压 | recorder 仍正常录制；系统按源时间处理完整分片，不会丢弃登记记录 |
| 某阶段失败 | 在任务详情点击“重试失败阶段”；已成功且指纹一致的前置阶段不会重跑 |
| 直播结束后任务失败 | 检查保留的失败批次并局部重试；草稿和普通子项目不会被删除 |
| 转场素材不可用 | 草稿仍可审阅；修复素材目录后重试，不会自动引用目录外 URL 或整片模板 |
| 取消智能任务 | 只停止该任务后续 AI 调度；不会停止 recorder，已有项目、转写、高光和草稿保留 |

任务错误和遥测只记录脱敏错误分类、模式、平台、阶段终态、耗时桶和聚合计数。日志或上报中不应
出现媒体、字幕正文、候选理由、主播/直播间标识、本地路径、Prompt、凭据、原始响应或内容指纹。

## 平台边界

智能成片依赖当前平台 Runtime Resource Pack 中经过校验的 FFmpeg、FFprobe、Whisper、VAD 和模型。
macOS arm64、macOS Intel x86_64 与 Windows x64 必须分别在真实目标机完成识别、预览和 H.264/AAC
导出验收；开发机单元测试或跨平台编译不能替代目标机证据。
